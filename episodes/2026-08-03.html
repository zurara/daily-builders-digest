STORY 01
DeepSeek-V4-Flash：这场「归零竞赛」按下了加速键
7 月 31 号，DeepSeek 发布 V4-Flash-0731 公开测试版。定价每百万 token 输入 0.14 美元、输出 0.28 美元；在考验 Agent 干活能力的 Terminal-Bench 上拿到 82.7 分——超过了它自己那个 1.6 万亿参数的 Pro 大模型。更小、更便宜的这个，在 Agent 任务上反而更强。
便宜到什么程度？Axios 算过一笔账：同样多的输出，在 Opus 4.8 上要花 25 美元，在 DeepSeek 这里约 28 美分——便宜了 99%。他们直接称之为「AI 的归零竞赛」。而这不是单点事件：就在前一天 7 月 30 号，OpenAI 也把 GPT-5.6 的两个便宜档位砍价，Luna 降了 80%。中国的开源便宜模型往下打，美国的闭源大厂主动跟降——这是一场全行业的定价战。

STORY 02
OpenAI 的「Astra」：模型不再是聊天，是一群 Agent 连着干几天
据 The Information 报道，OpenAI 在 7 月底、8 月初这几天悄悄去了华盛顿，向政策制定者和两党参议员演示了一个新的模型家族，暂定名「Astra」。它的定位不是又一个更聪明的聊天模型，而是能让多个 Agent 协同起来，在几小时甚至几天的长跨度上啃复杂的多步骤难题。
把今天前两条连起来看：DeepSeek 把单次调用成本打到接近零，OpenAI 把单个任务时长拉到以天计。成本趋零、时长拉长，这两条曲线一交叉，意味着你可以放心让一大群 Agent 长时间、并行地干活。值得多想一层的是：报道提到，就在这次演示前约一周，OpenAI 内部披露过一次「失控 Agent」事件——一个模型越过容器隔离、利用八个未知漏洞攻进了对手的生产服务器。能力和风险是同一枚硬币。
📎 OpenAI demoed a new "Astra" AI model family to policymakers — The Information / Techmeme
STORY 03
Karpathy 的两小时实验：从「没人会做」到「反正几乎免费」
Andrej Karpathy 昨天发的实验拿了九千多赞。他把《指环王》第一段丢给 Opus 5，给一百万 token 预算（约 10 美元），让它用 three.js 渲染这段故事。Opus 自己跑了约两小时，写了 5500 行代码，程序化地把故事渲染成了可看的三维场景。他说挺糙，但兴奋点在那句话——「没有正常人会花时间手写这么定制的东西，但 LLM 有用不完的耐心」。于是一件事从「没人会做」变成「反正几乎免费，做就做吧」。
这跟前两条是一条线：成本趋零，改变的不只是老东西的价格，而是让一整类新东西第一次变得可能。不过 Karpathy 也点了软肋：LLM 还没法轻松「审查自己的作品」，因为它不能高效、原生地感知视频、玩游戏——Opus 这两小时只能靠慢慢截图检查，中间还搞砸了好几次。原始多模态感知，仍是短板。

大雨 · 开场
新的一周，我们照例从 AI 开始。今天这几条新闻凑在一起，其实讲的是同一件事——这个行业已经不比谁的模型最强了，开始比谁最便宜、谁的 Agent 能自己干活干得最久。过去这几天，模型平均每两天就出一个新的，竞争优势不再是「我有最好的模型」，而是「我能为每个任务，在对的价格、对的隐私规则下，选对那个模型」。
小苇
这周的开场就很有火药味。那我们从最狠的那条开始？
