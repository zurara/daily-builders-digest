🎧今日音频· AI 星期一 · 大雨 × 小苇

◈ 开场

大雨
早上好，欢迎收听每日快报。今天是七月二十七号，星期一，我们又回到了 AI 主题。这周开局特别猛，前脚 Anthropic 刚把 Claude Opus 5 甩出来登顶各大榜单，后脚整个行业围绕"开放权重"吵成一团，AI Agent 的融资也在疯狂加速。小苇，准备好了吗？
小苇
准备好了。说实话我周末就一直在刷 Opus 5 的评测，感觉这一次的分数有点吓人。咱们就从它开始聊吧？
STORY 01
Claude Opus 5 登顶，Agent 能力甩开一个身位
大雨
Anthropic 在七月二十四号发布了 Claude Opus 5，三天时间就把独立评测机构 Artificial Analysis 的两个核心榜单都拿下了：综合智能指数六十一分，Agent 能力指数五十五点三分，两项都是第一，压过了 Fable 5 和 GPT-5.6 Sol。
小苇
综合第一我理解，但你特别强调了 Agent 能力指数。这个指标为什么重要？
大雨
因为它衡量的不是"聊天聊得好不好"，而是"能不能自己把一件多步骤的活儿干完"。今年大家真正在意的，是模型能不能像一个员工一样，自己规划、调用工具、连续操作几十步不翻车。Opus 5 在 Frontier-Bench 这个专测 Agent 编程的榜单上拿了四十三点三分，在 ARC-AGI-3 这个考新颖推理的榜单上拿了三十点二分——差不多是第二名的三倍。
小苇
三倍这个差距太夸张了。那价格呢？这么强会不会贵到用不起？
大雨
每百万 token 输入五美元、输出二十五美元。不算便宜，但考虑到它能替代的工作量，很多团队会觉得值。真正的信号是：前沿模型的天花板还在往上顶，而且是往"能干活"的方向顶，不是往"更会说话"的方向。
📎 来源: Claude Opus 5 Benchmarks Explained — Vellum
STORY 02
开放权重成了行业共识
大雨
第二条其实是这周社交媒体上最热闹的一场辩论——开放权重，也就是 open weights。GitHub Copilot 这周加进了它第一个开放权重的编程模型，而更大的信号是 Google 也公开站队支持开放权重。
小苇
我看到 Box 的 CEO Aaron Levie 发了条推特，说"现在连 Google 都上船了，这是对开放权重 AI 的一次完整背书"。为什么大公司站队开放权重是件大事？
大雨
因为过去两年，最强的模型几乎都是闭源的、只能通过 API 调用。开放权重意味着你能把模型权重下载下来，自己部署、自己微调、数据不出门。对企业来说这是安全和成本的双重解法。当 Google 这种量级的玩家也开始背书，等于告诉整个市场：闭源不再是唯一的赢家路径。
小苇
那闭源阵营是什么反应？
大雨
有意思的是并没有对着干。开发者 Peter Steinberger 就说，OpenAI 也签署了那封支持开放生态的联名信，他原话是"竞争对生态是好事，大规模地把模型跑起来本身就很难"。这说明连最头部的实验室都意识到，开放和闭源不是你死我活，而是会长期共存。
📎 来源: GitHub Copilot adds open-weight coding model — Crescendo
STORY 03
AI Agent 一月融资十八亿美元
大雨
第三条讲钱。七月一个月，AI Agent 创业公司拿到了十八亿美元融资，分布在十二笔以上的交易里，其中做企业级自动化 Agent 的公司拿走了百分之五十八的资金。最亮眼的一笔是法律 AI 公司 Harvey，两亿美元的 C 轮，估值二十一亿。
小苇
钱都往"企业自动化"这个方向涌，是不是说明消费级 Agent 反而没那么受追捧了？
大雨
至少投资人现在更看好企业端。Gartner 给了个数字很能说明问题：到今年年底，百分之四十的企业软件里会内嵌 Agent，而 2025 年这个比例还不到百分之五。同时 Gartner 也警告，有两千三百四十亿美元的企业软件支出正因为 Agent 化而面临洗牌风险。
小苇
洗牌风险，意思是老牌软件公司可能被 Agent 取代？
大雨
对。如果一个 Agent 能直接帮你把活干了，你还需要那么多点来点去的传统软件界面吗？这是今年悬在每一家软件公司头上的问题。
📎 来源: AI Agent Startup Funding July 2026 — AI Funding
STORY 04
阿里云推出「Agent 原生云」
大雨
最后一条把视角切到中国。在七月十八号的世界人工智能大会上，阿里云发布了"Agent 原生云"，一套专门为 AI Agent 设计的云架构。里面有三块：AgentTeams 做多 Agent 协同编排，Agentic Computer 提供安全的沙箱执行环境，还有专门为可复用 Agent 技能调优的基础设施。
小苇
听起来是把"跑 Agent"这件事当成云计算的一等公民来设计了。这和普通云有什么本质区别？
大雨
普通云是为人写的程序设计的——你部署一个服务，它老老实实跑。但 Agent 是会自己做决策、自己调工具、甚至自己写代码去执行的，你必须给它一个既能放手让它干、又能随时收得回来的环境。沙箱、编排、权限，这些以前是可选项，现在变成了地基。
小苇
所以云厂商的竞争，正在从"谁的算力便宜"变成"谁更懂怎么安全地养 Agent"。
大雨
说得好。这就是今年基础设施层最深的一条暗线。
📎 来源: AI News for the Week of July 24 — Solutions Review
