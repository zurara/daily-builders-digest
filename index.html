🎙 对话全文 · 大雨 × 小苇
一个人用，还是一起用
大雨 · DAYU
欢迎来到 Daily Builders Digest，今天是二〇二六年十月二十一号，星期三，产品日。我是大雨。
小苇 · XIAOWEI
我是小苇。上周我们聊的是「把整件事走一遍」。这周有什么？
大雨 · DAYU
四条。第一条，Replika 的创始人 Eugenia Kuyda 发布了 Wabi 2.0，一个可以拉人进群一起用的 AI 助手。第二条，ChatGPT 开始推出 Slides，在对话里做幻灯片，团队可以一起改。第三条，很多人在用 Claude Code 这类 agent 把自家智能电视的广告和预装软件删掉。第四条，Figma 发布了 Specs，用来把设计规则写下来，给人和 agent 一起看。
小苇 · XIAOWEI
这四条放在一起，想说什么？
大雨 · DAYU
过去两年，AI 产品基本是一个人对着一个对话框。这一周的几条新闻，问的都是同一个问题：这个 AI 是给一个人用的，还是给几个人一起用的？几个人一起用的时候，谁能看到什么、谁说了算、规则写在哪？
01Wabi 2.0：把 agent 拉进群聊
大雨 · DAYU
先说事实。十月十九号，Eugenia Kuyda 正式对所有用户开放 Wabi 2.0，目前免费。她十二年前在 TechCrunch Disrupt 台上讲过一个帮人订餐厅、订旅行的聊天机器人，那家公司后来转型做了 Replika。去年她卸任 Replika CEO，创办了 Wabi。
📎 来源: Replika's founder built the AI assistant she pitched at Disrupt 12 years ago — TechCrunch
小苇 · XIAOWEI
Wabi 1.0 不是做小应用的吗？
大雨 · DAYU
对。1.0 是用提示词生成小应用，再分享给朋友。她说团队这一年发现，用户喜欢为自己定制的软件，但不想花时间去搭。所以 2.0 改成一个聊天应用：你连上邮箱，agent 自己开几个对话线程，每个线程管一件事，再自己决定在线程里搭什么小应用。比如健康线程里有一个减重记录，家庭线程里有一个附近儿童活动的列表。
小苇 · XIAOWEI
那跟其他个人助手有什么不一样？
大雨 · DAYU
她说了两点。第一，多个线程，不是一个线程。她原话是：只有一个对话的产品，用久了会变差，因为所有东西都堆在一个没完没了的对话里。第二，线程可以分享给别人，变成群聊。她演示的时候，有一个线程是和男朋友共用的，里面有现场演出提醒、餐厅清单、两人在读的书；另一个是家庭线程，管女儿的日程。
小苇 · XIAOWEI
群里的人能看到我的邮箱吗？
大雨 · DAYU
这是最需要设计的地方。按她的说法，权限按单个对话划分，你在这个群里共享多少由你决定。群里有人请求查看某人的个人信息时，所有人都能看到这次请求。比如她男朋友可以在群里问：「Eugenia 下周四有空吗？」
小苇 · XIAOWEI
有人用了怎么说？
大雨 · DAYU
投资人 Nikunj Kothari 写了一段很具体的反馈。他说现在的个人 agent 分两种：一种是单线程的，事情一多就分不开；另一种是自己搭的多对话 agent，能共享上下文，但每个对话一直留着。Wabi 是一个主 agent 加上若干单一用途的对话，会主动生成，用完就归档。他去纽约出差，Wabi 看到机票就开了一个线程，旅行结束后自动归档。他的批评是：太主动了，生成的小应用还不够好。
小苇 · XIAOWEI
「用完就归档」这一点挺重要。
大雨 · DAYU
对。做产品的人可以拿这个检查自己：你的 AI 功能里，对话和任务有没有结束的时候？结束以后去哪？另外一件事：如果你的产品里有两个人共用一个 AI，你得先回答，谁的数据在这个空间里可见，谁发起的操作要谁来确认。
02ChatGPT Slides：对话最后变成一份能一起改的文件
大雨 · DAYU
第二条。OpenAI 正在推出 ChatGPT Slides。它是上个月发布的 ChatGPT Space 的一部分，Space 里规划了 Pages、Slides、Sheets 三个工具。Slides 可以从对话、上传的文件或者大纲生成一份幻灯片，也可以从内置模板开始。
📎 来源: ChatGPT Slides is finally here to turn your chats and files into presentations — Android Authority
小苇 · XIAOWEI
生成幻灯片的工具很多了。
大雨 · DAYU
这次的重点在后面。做好以后可以分享给同事，大家实时一起改、留评论，还可以让 ChatGPT 按团队的评论自动改。改完可以在 PowerPoint 或 Google Slides 里打开，也能导出 PDF 或 PowerPoint 文件。目前开放给 Pro、Business 和 Enterprise 用户，Plus 用户暂时没有。
小苇 · XIAOWEI
所以对话框不再是终点。
大雨 · DAYU
是。以前的流程是：在对话里问，复制答案，粘贴到别的软件里，再发给同事。现在 OpenAI 想把后面几步也留在自己的产品里。这跟 Wabi 是同一个方向：AI 产出的东西，要能被好几个人一起看、一起改。
小苇 · XIAOWEI
对做产品的人意味着什么？
大雨 · DAYU
如果你的产品是一个「AI 生成某种文件」的工具，你要问自己：生成之后呢？第二个人进来改的时候，AI 还认不认得这份文件的上下文？评论能不能直接变成修改？导出以后，用户还会不会回来？
03用 AI 把智能电视变笨
大雨 · DAYU
第三条，一个用户这边的故事。TechCrunch 十月十九号报道，很多人在用 AI agent 清理自家的智能电视：删开机广告、删预装软件、关掉收视追踪、换一个更快的主屏。
📎 来源: People are using AI to make their smart TVs dumb again — TechCrunch
小苇 · XIAOWEI
怎么开始的？
大雨 · DAYU
一个叫 Gathin 的开发者，十月十七号发帖说，他爸妈的电视在进 Netflix 之前先放一段赞助广告。他把电视型号给了 Claude Code，Claude Code 在 Wi-Fi 上找到电视，删掉了二十五个小米的预装包，写了一个新的主屏。他把提示词放到 GitHub 上，叫 cleanyourtv。他说接下来两天里有几千人照着做，小米、TCL、索尼、Fire TV、LG 都有。
小苇 · XIAOWEI
不用 root？
大雨 · DAYU
报道说不需要 root，也可以恢复出厂设置。另一个项目叫 dumbtv，它的 GitHub 页面写的是：你的电视应该只做你花钱买的事，你的应用、你的 HDMI 输入，别的都不要。不要电视自己放的广告，不要收视追踪，不要你没要求的更新。用法是把你的 agent 指向这个仓库。
小苇 · XIAOWEI
有翻车的吗？
大雨 · DAYU
有。有人说把安卓电视刷坏了，有人做到一半卡住了，也有人说直接让 Claude「黑掉我的电视」，它不回应，要写更具体的提示词。
小苇 · XIAOWEI
这对做产品的人是个警告吧。
大雨 · DAYU
我觉得是。以前用户受不了你的产品，最多换一个。现在用户可以让 agent 直接改掉你的产品，把广告、追踪、慢的启动器一起拿掉。TechCrunch 也提到，如果这种做法普及，会影响靠收视数据和主屏广告赚钱的智能电视广告业务。一个问题可以留给自己：你的产品里有哪些东西，是用户如果有能力就会删掉的？
04Figma Specs：把规则写下来，给人和 agent 一起看
大雨 · DAYU
第四条稍早一点，是十月十四号到十五号 Figma 在印度的第一场 Config 上发的，上周没来得及讲。Figma 发布了 Specs，一个用 Markdown 写的编辑器，用来定义一家公司的设计语言。团队和 agent 都可以引用它。Specs 可以是单独的文件，也可以放在画布里，里面可以引用画布上的元素，嵌入 FigJam 图、代码图层和设计稿。
📎 来源: Figma announces new features to define how agents work on its platform — TechCrunch
小苇 · XIAOWEI
为什么现在需要这个？
大雨 · DAYU
因为 Figma 前一周刚把画布上的 agent 开放给更多用户。AI 的输出不确定，Figma 就提供工具，让 agent 的结果更可预测。同一场活动里，代码图层进入公开测试，MCP 新增了二十多个接入的工具。
小苇 · XIAOWEI
有什么数字？
大雨 · DAYU
Figma 首席设计官 Loredana Crisan 给了一组数字：现在写出来的代码行数是过去的十七倍，但发布次数只多了一点三倍。她的解释是，很多代码不是为了上线，而是为了搞清楚产品应该是什么样子。
小苇 · XIAOWEI
这和前面几条怎么连上？
大雨 · DAYU
一个人用 AI 做设计，规则在他自己脑子里。一个团队加上几个 agent 一起做，规则就得写下来，放在大家都能看到的地方。Specs 做的就是这件事。
小条苹果十月二十八号开发布会
大雨 · DAYU
一条小的。苹果宣布十月二十八号在洛杉矶开产品发布会。分析师预计会发新款 Mac，Melius Research 的分析师 Ben Reitzes 写道，他预计今年秋天会有一款触屏笔记本。我们下周三再看。
📎 来源: Apple announces product launch event for Oct. 28 — CNBC
关注建造者
大雨 · DAYU
最后是建造者动态。先说播客。Every 的 AI & I 这期，Dan Shipper 和 Every 的平台负责人 Willie Williams 聊，为什么 Every 从「每人一个个人 agent」改成了「全公司一个 agent」。
小苇 · XIAOWEI
为什么改？
大雨 · DAYU
他们说今年初公司里每个人都有自己的 OpenClaw agent，最大的好处是大家能在 Slack 里看到别人怎么用 AI。但问题也很多：安全难管，设置复杂，经常坏，不维护就慢慢没用了，还得记住哪个 agent 擅长什么。Willie 的结论是：与其每个人各自维护，不如把力气放在一个全公司都受益的 agent 上。他判断工作里会是一个公司一个 agent，在家里会是一个人或者一家人用一个个人 agent。
📎 来源: AI & I by Every — Why Every Traded Personal Agents for One Company Agent
小苇 · XIAOWEI
正好和 Wabi 那条对上。推文呢？
大雨 · DAYU
点赞最多的是 Anthropic 做 Claude Code 的 Thariq：很多同时开好几个 agent 干活的人，可以慢下来。你做的大部分事其实不重要。你的最高优先级是什么？如果你把全部注意力放在它上面，会是什么样？
小苇 · XIAOWEI
这条五千多赞。
大雨 · DAYU
第二条，Vercel CEO Guillermo Rauch 说他们开源了一个很快的 HTML artifact 构建器，底层是 libfx，让 agent 在服务器崩溃、模型不稳定、函数时长限制的情况下也能接着跑。他说给 v0 搭这些底层管道很痛苦，现在免费开源了。
小苇 · XIAOWEI
还有吗？
大雨 · DAYU
Y Combinator 的 Garry Tan 转发 Wabi，说多人 agent 做成群聊几乎是必然的，Wabi 已经做出来了。还有 Box 的 Aaron Levie，他说模型越强，按行业做差异化的空间反而越大。模型弱的时候，你只能做一个套壳；现在 agent 要用工具、跑几小时几天的任务、协调多个 agent、接行业数据、改变工作流程，专门化的空间更大了。
小苇 · XIAOWEI
今天的四条，你会怎么收尾？
大雨 · DAYU
一个动作：打开你的产品，找一个 AI 功能，假设第二个人加入进来。他能看到什么？他能改什么？规则写在哪？这三个问题答不上来，就先写下来。
小苇 · XIAOWEI
好。我是小苇。
大雨 · DAYU
