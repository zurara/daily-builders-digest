◈ 本周四条新闻，各自说明了什么
产量能说明工厂在动，说明不了机器人在干活
01特斯拉。8 月每周数百台，二季度每周数十台。大部分用于内部测试、训练、数据采集。V3 不是最终客户版本。手部装配、触觉传感器耐用性、AI 泛化仍是问题。
02智元。累计 20,000 台，最近三个季度每季约 5,000 台。其中 G 系列轮式 5,605 台（28%）。数字是产量，不是销量或在役部署量。
03英伟达 × Figure。OpenShell 在 agent 外部限制它能做什么，Sentry 在独立硬件上监控。放到机器人身上还要解决物理问题：中断一个正在走路的机器人，本身也要设计。
04Niantic × Asimov。场景可以买（100 个真实环境，视觉与碰撞对齐），行走训练方法可以下载（奖励、域随机化、执行器参数全部公开）。两者都没有给出真机效果数据。
05该看的数字。任务完成率、人工干预次数、正常运行时间、维护要求、客户验收。本周所有新闻都没有给出这组数字。

◈ 今日脚本 · 大雨 × 小苇

◈ 开场：造出来，和干上活

大雨
周二好，欢迎回到每日快报。今天是九月二十九号，机器人星期二。上周我们讲的是一个数字：IFR 统计，二〇二五年全球人形机器人一共卖出去七千台。这周的新闻，正好接着那个数字往下走。
小苇
怎么接？
大雨
这周有两条关于产量的新闻。一条说特斯拉现在一周能造几百台 Optimus。另一条是智元机器人宣布，累计产量到了两万台。
小苇
那数字一下子就大了。
大雨
大了。但这两条新闻里都有同一句话：造出来的机器人，大部分还没有在给客户干活。另外两条新闻讲的就是中间缺的东西：一条是安全，Figure 加入了英伟达的一个 agent 安全平台；一条是训练场，Niantic 卖真实场景给机器人做仿真训练，Asimov 把人形机器人走路的训练代码开源了。
小苇
所以今天的问题是：从造出来到干上活，中间还差什么。
大雨
对，就这个问题。

◈ 第一条：特斯拉一周几百台 Optimus，但不是给客户的版本

大雨
先说特斯拉。九月二十五号，The Information 发了一篇报道，Humanoids Daily 第二天做了整理。报道说，八月份特斯拉在 Fremont 工厂一周能造几百台 Optimus。二季度的时候还是小批量试产，一周几十台。差不多涨了十倍。
小苇
十倍，几个月之内。
大雨
对。管理层的目标是到二〇二六年底，建成一条每周能产一千台以上的连续自动化产线，长期目标是每周两万台。但要注意，这些是产能目标，不是已经做到的产量，也不是交付给客户的数量。

📎 来源: Tesla Reportedly Builds Hundreds of Optimus Robots a Week

小苇
那现在造出来的这几百台在干什么？
大雨
报道说，大部分用在内部：测试、训练、采集数据。在特斯拉自己工厂里干活的那些，是在划定的区域里、有人紧盯着、做事先编好程序的具体任务。
小苇
这听起来跟上周 IFR 说的一样。机器人造出来，先拿去喂数据。
大雨
一样。还有一点：现在产线上造的叫 Optimus V3，比之前更轻，摄像头更多，外形更像人。但报道的消息来源说，这不是最终卖给客户的版本。客户版本还在开发，耐用性和可靠性的要求更高。
小苇
那问题出在哪？
大雨
报道列了几个具体问题。第一是手。一套手加前臂，有一百多个螺丝和小零件，现在都要人工装配。产线一开快，有些工装夹具就不稳，返工的机器变多。第二是触觉传感器不耐用。特斯拉的做法是做一个可更换的传感手套，传感层坏了只换手套不换整只手，计划二〇二七年用上。
小苇
所以手套这个方案，说明问题还没解决。
大雨
对，这是应对方案，不是问题已经解决的证据。第三是 AI。三个知情人士说，Optimus 现在还不能可靠地完成很多种任务，遇到不熟悉的情况会出现不可预测的行为。学一个基本任务还是要花好几天。
小苇
数据方面呢？
大雨
特斯拉有超过五十万小时的训练数据，目标是年底翻倍。数据来源是遥操作示范、动作捕捉设备，还有录人做体力活的视频。报道里还有一个细节：有些工厂工人不愿意录示范，因为这些机器是要来替代他们的。后来特斯拉就专门雇了采集员，大部分采集也挪到了产线之外。
小苇
这个细节挺说明问题的。机器人要学人的工作，第一个要说服的是那个人。
大雨
商业计划方面，报道说特斯拉最开始打算租，不打算卖，租给工厂或仓库跟它自己差不多的客户。租的好处是机器可以收回来升级、翻新，客户那边的部署也能回传数据。但报道里没有提到任何已签的租约，也没有交付时间表。
小苇
那我们应该看什么数字，才能判断它真的能用了？
大雨
Humanoids Daily 列了一组，我觉得是对的：任务完成率、人工干预次数、正常运行时间、维护要求、客户验收。产量只能说明工厂在动，说明不了机器人在客户那里能不能干活。

◈ 第二条：智元累计两万台，但两万台不是同一种机器人

小苇
第二条是智元。
大雨
智元机器人，上海的公司。九月二十四号宣布，累计产量到了两万台，第两万台交付给了长隆，是一台 A3 Ultra。时间线是这样的：去年十二月五千台，今年三月一万台，六月一万五，九月两万。
小苇
每个季度加五千。
大雨
对，最近三个季度都是大约五千台。所以更准确的说法是产能很稳定，不是一直在加速。累计从一万翻到两万，不代表工厂的生产速度翻倍了。

📎 来源: AGIBOT Has Built 20,000 Robots—Twice Its March Total

小苇
两万台都是人形机器人吗？
大雨
不是，这一点很重要。智元公布了分系列的数字：A 系列，就是全尺寸双足人形，五千六百三十八台；X 系列，小一点的双足人形，八千七百五十七台；G 系列，是轮式的工业任务机器人，五千六百零五台。
小苇
所以四分之一多是轮式的。
大雨
百分之二十八是轮式。最多的是 X 系列，占百分之四十四。而且这些都是产量，不是销量，也不是正在运行的部署量。
小苇
那第两万台交付给长隆，是在做什么？
大雨
长隆是珠海的主题乐园。智元和长隆一起在长隆宇宙飞船乐园部署了三百多台机器人，做表演、导览、酒店服务，还成立了一个文旅研究院。这是一个有名字的客户、有具体场景的部署。但三百台只占两万台的一小部分。
小苇
把特斯拉和智元放在一起看，我有一个感觉：两家的路线完全不一样。
大雨
说说看。
小苇
特斯拉是一款机器人，先在自己工厂里用，目标是每周两万台。智元是好几个系列，双足、轮式都有，卖给乐园、酒店、商店、工厂，哪个场景能用就先进哪个场景。
大雨
这个对比是对的。一个是先把一款产品做到极致再铺开；另一个是先让不同形态的机器进入能用的场景。上周 Agility 也说在考虑做轮式机器人。说明至少有一部分公司已经认为，不一定所有场景都需要腿。

◈ 第三条：Figure 加入英伟达的 agent 安全平台

小苇
第三条换个方向，讲安全。
大雨
九月二十八号，英伟达 CEO 黄仁勋宣布了一个叫 Open Agent Safety Platform 的计划，开放 agent 安全平台，说有一百多家合作伙伴。Figure 的 CEO Brett Adcock 发帖确认参加，他的原话是：人形机器人很快会进入家庭和工作场所，它们必须安全、值得信任。

📎 来源: Figure Joins NVIDIA's Open Agent Safety Platform as Humanoid Deployment Approaches

小苇
这个平台具体做什么？
大雨
两部分。第一部分叫 OpenShell，是一个开源的运行环境。每个 agent 跑在一个隔离的沙盒里，能读哪些文件、能调用哪些系统功能、能连哪些网络，都有限制。而且这些限制是在 agent 外面执行的，不靠 agent 自己守规矩。
小苇
就是说，就算模型做了一个坏决定，它也做不了超出权限的事。
大雨
对。英伟达区分得很清楚：提示词和训练出来的行为，影响的是模型想做什么；运行环境限制的是它实际能做什么。第二部分叫 Sentry，是一个可选的监控层，跑在单独的 BlueField 硬件上，agent 和它所在的主机碰不到它。英伟达说能在几毫秒内把一个 agent 隔离掉。
小苇
那放到机器人身上，意味着什么？
大雨
原则是有用的：负责决定动作的系统，不应该同时是唯一负责检查这个动作的系统。但 Humanoids Daily 提醒得对，机器人比软件 agent 多了一层物理问题。比如说，限制访问机器人的控制接口，能挡住一个未授权的指令。但它不能保证一个已授权的抓取用的力气是合适的。还有，如果你突然中断一个模型，一台正在走路的机器人会不会摔倒？
小苇
软件里的"立刻停止"，到了物理世界不一定是安全的。
大雨
对。停下来本身也是一个动作。
小苇
那 Figure 具体会怎么用？
大雨
还不知道。Adcock 的帖子没说 Figure 会贡献什么、哪个系统会用。英伟达公布的合作伙伴图里，Figure 好像是唯一一家专门做人形机器人的公司，另外还有 Gecko Robotics 和 Skild AI。Gecko 的 CEO 在 CNBC 讲了一个更具体的例子：用 agent 规划检测机器人的路线，决定在哪些表面多采集数据，但一直在人设定的范围里，而且人随时可以收回。
小苇
这个我能理解。人定边界，agent 在边界里规划，人保留叫停的权力。
大雨
对。还有一个背景：上周有一个叫 RoboHarm 的测试，发现 GPT-6 Astra 很少拒绝不安全的机器人指令。那个研究没有测英伟达这个平台，但它说明了一件事：一个模型能不能完成任务，和它会不会拒绝危险指令，是两种不同的能力。

◈ 第四条：训练场正在变成一门生意

小苇
第四条是训练场。
大雨
两件事放在一起说。第一件是 Niantic Spatial，就是做 Pokémon GO 的 Niantic 分出来的那家做空间计算的公司。九月二十五号发布了一个叫 Places Library 的场景库，一开始有一百个真实环境，给机器人做仿真训练和评估。

📎 来源: Niantic Spatial Launches Places Library With 100 Real Environments for Robot Training

小苇
真实环境是什么意思？
大雨
就是真实拍下来的地方，比如斯塔滕岛的一个医疗仓库、新泽西的一个货架区、伦敦和旧金山的街道。每个环境里有两层东西：一层是高斯泼溅，负责看起来像真的；另一层是碰撞网格，负责告诉机器人哪里能走、哪里会撞上。两层是从同一次重建里出来的，所以看到的边缘和碰到的边缘是对齐的。
小苇
为什么对齐这么重要？
大雨
举个例子。一个仿真机器人走向货架，如果摄像头看到的货架边缘和物理引擎里的货架边缘差了几厘米，机器人看到的和碰到的就对不上，学出来的东西到了真实世界就不准。
小苇
这个生意怎么收钱？
大雨
有两个免费样例，其他要付费。评估档最少签三个月，可以下载十五个场景，每个月十五分钟的自采拍摄额度。训练档最少签一年，一百个场景，每个月六十分钟拍摄额度。拍摄额度的意思是，你可以把自己的工厂拍下来加进去。页面上没写价格，要找销售谈。
小苇
效果有数据吗？
大雨
这次发布没有给出真实机器人成功率提高了多少。之前有一个例子：瑞士的 Flexion 在七月份用 Niantic 重建的办公室训练了一个导航策略，说是零样本迁移到了真实办公室，家具挪了位置也能应对。但那是在场景库发布之前做的，不能直接当作这一百个场景的效果。
小苇
第二件呢？
大雨
第二件是 Asimov，Menlo Research 做的一个开源人形机器人项目。他们之前已经开源了 CAD 和仿真文件，还在卖 DIY 套件。九月二十五号，他们把 Asimov 1 走路的训练代码开源了。

📎 来源: Asimov Open-Sources the Training Code Behind Its Humanoid's Walk

小苇
开源的具体是什么？
大雨
一个基于英伟达 Isaac Lab 的训练框架，BSD-3 许可证。里面能看到奖励怎么设：跟上指令速度、保持站立有奖励；脚打滑、动作突变、自己撞自己要扣分。还能看到仿真里故意加的变化：脚底摩擦力、关节初始位置、执行器增益，还有外力干扰和带噪声的传感器读数。
小苇
故意加干扰，是为了让它到了真机上不那么脆弱。
大雨
对，这是在处理仿真到真机的差距。每个关节的扭矩上限、刚度、阻尼、摩擦、执行器延迟也都能改。如果你改了机器人的硬件，就可以在这里改仿真参数。有一个问题要说一下：Asimov 的公告说包含一个训练好的策略检查点，但 Humanoids Daily 去仓库和 GitHub 发布页查了，没找到可以下载的检查点。
小苇
所以现在能拿到的是训练方法，不是训练好的模型。
大雨
对。把这两件事放在一起：Niantic 卖场景，Asimov 开源训练方法。以前走路和场景都是每家公司自己关起门来做的，现在开始变成可以买、可以下载的东西。

◈ 收尾：这周该记住什么

小苇
把四条串起来吧。
大雨
特斯拉和智元说明，产量正在上去，一周几百台，一个季度五千台。但特斯拉的机器大部分在内部采数据，智元的两万台是好几种不同的机器。英伟达和 Figure 说明，让 agent 能安全地做事，已经有人在搭基础设施，但到了机器人身上，"停下来"本身也要设计。Niantic 和 Asimov 说明，训练需要的场景和方法开始变成公共资源。
小苇
所以判断一家公司的机器人能不能干活，看的不是它造了多少台。
大雨
对。看的是在某个具体任务里，它能完成多少、要人帮几次、一天能正常运行几个小时。这周所有新闻都没有给出这组数字，这也是这周最值得记住的一点。
小苇
还有一件事，Figure 那边说九月三十号要给 Figure 02 办一个告别。
大雨
对，明天。Adcock 发了一个 AI 生成的预告，说要像终结者那样把退役的 Figure 02 熔掉。另外这周 IROS 正在匹兹堡开，到十月一号结束。有新消息我们下周说。

◈ 关注建造者 · 今日建造者动态

大雨
最后是关注建造者。今天的推文没有直接讲机器人的，但有几条讲的问题跟今天一样：新技术看起来很厉害的时候，怎么判断它是不是真的在起作用。
小苇
先说点赞最多的那条。
大雨
Thariq，在 Anthropic 做 Claude Code。他说：我最担心的是，我们会因为变得更懒，把 agent 带来的生产力提升都吃掉。四千多个赞。
小苇
这句跟特斯拉那个故事有点像。工具变强了，但人怎么用它，决定了最后的结果。
大雨
第二条是 Zara Zhang，就是 follow-builders 这个项目的作者。她说：新技术可以耀眼到让我们看不见它哪里不管用。有时候还会让你觉得，如果某个东西不管用，那可能是你的问题，不是技术的问题，因为世界变得太快，每个人好像都走在你前面。
小苇
这句话放在今天特别合适。一周几百台、累计两万台，这些数字都很耀眼。
大雨
对，所以我们今天一直在问：这些机器到底在干什么。第三条是 Box 的 CEO Aaron Levie。他说，当 agent 开始替用户做最好或最高效的选择时，有两类市场会受影响。一类是靠用户懒得换来赚钱的市场，这些市场的切换成本会降低，竞争会加剧。另一类是因为太麻烦而被压住的市场，比如医疗、旅行、本地服务，agent 会让这些东西变得容易买，反而释放出新的经济活动。
小苇
最后一条？
大雨
Matt Turck，FirstMarkCap 的投资人，MAD Podcast 的主持人。他说：值得注意的是，很多真正懂 AI 怎么工作的研究者，既不相信 AI 末日论，也不相信大规模失控加速；反而是不太懂的人，观点非常确定。
小苇
播客呢？
大雨
这周推荐 The Robot Report 播客第二百六十三期，嘉宾是 General Robotics 的 CTO Sai Vemprala，他之前在微软研究院做研究员。他们的做法跟现在主流不一样：不训练一个什么都会的大模型，而是把专门的能力组合起来，让机器人能换任务、换形态。节目开头还过了一遍上周的新闻，包括 Agility 考虑轮式机器人、波士顿动力开 Atlas 训练中心、高通收购 PickNik。
大雨
好，今天就到这儿。明天是产品星期三。周二快乐，明天见。
