STORY 01
Fable 5.1 与 Mythos 5.1：被砍掉的，是「重读」的钱
9 月 1 号，Anthropic 同时发布 Claude Fable 5.1 和 Mythos 5.1。先说清楚一件容易搞混的事：这两个名字底下是同一个模型。Fable 5.1 是通用版本，带生产级安全防护；Mythos 5.1 是限制访问版本，给通过审核的网络安全与生命科学机构使用——他们的工作恰好需要那些防护平时会拦住的能力。这是一个治理设计，不是产品档位。规格上，两者都支持 100 万 token 上下文、单次输出上限 12.8 万 token；Anthropic 称其在编码、知识工作与长跨度问题求解上超过 Fable 5、Opus 5 及 OpenAI 的 GPT-5.6 Sol。
但真正值得记的在小字里：缓存读取从每百万 token $1.00 降到 $0.25，砍掉 75%。这个数字对聊天用户几乎没意义，对跑 Agent 的人是另一回事。聊天是不断往上加新内容；Agent 干活是反复回头读同一份上下文——每调用一次工具、每走一步，前面那一大坨系统提示、文件、之前的推理都要再过一遍。一个跑两小时的任务，同一份上下文可能被读几百次。所以这次降价是专门给长任务打的折，不是给所有人打的折。同时新增的 beta 功能「会话中途调节 effort」，让你在一次会话里随时调整某一步花多大力气——从「开工前选模型」变成「每一步配预算」。

STORY 02
Gemini 3.8 Flash：同价更强，但要看你按什么计量
9 月 2 号，Google 发布 Gemini 3.8 Flash，附带一个安全向变体 3.8 Flash Cyber。价格与 3.7 Flash 持平：每百万输入 $0.75、输出 $3.75。基准分全线上涨——DeepSWE v1.1 从 65.3% 升到 73.7%（+8.4 分），Terminal-Bench 2.1 从 85.8 到 89.4，OSWorld-2.0 从 50.6 跳到 59.0，Terminal-Bench 4.0 从 11.2 几乎翻倍到 19.1。三项基准上超过 Claude Opus 5。
两个附注必须读。第一，这个价格有期限：$0.75 / $3.75 只到 2026 年 12 月 31 日，2027 年 1 月 1 日双双翻倍为 $1.50 / $7.50。如果你正拿这个价格做商业模型，把日期写进去。第二个更有意思：3.8 Flash 不是新的基础模型，它建在 3.7 Flash 之上，而它拿到那些分数的方式是刻意「更用力地想」——烧掉更多思考 token。所以 Google 自己在文档里直说：效率优先的负载，请继续用 3.7 Flash。一家公司在发布日告诉你别升级，少见，但诚实。它提醒的其实是：「同价更强」成不成立，取决于你按什么单位算——按每百万 token 标价，它没涨；按每完成一个任务的总花费算，它可能是涨的。

STORY 03
Muse Spark 1.3：唯一真正让账单变小的那种进步
同样是 9 月 2 号，Meta 发布 Muse Spark 1.3，当天在 Muse Code 与 Meta Model API 上线。Zuckerberg 称其为「几乎便宜到不值得计量的前沿性能」，是他们「在编码和 Agent 工作上迄今最大的一次跳跃」。具体数字才是重点：Meta 工程师的并排对比显示，完成同样的任务，1.3 比 1.2 少用约 20% 的工具调用、少烧约 25% 的 token；DeepSWE 上涨 16 分，现在与 GPT-5.6 Sol 和 Claude Opus 5 互有胜负。
注意它没有降价——它降的是你要买的量。这是今天三种降本方式里最干净的一种：Anthropic 是单价下调，Google 是单价不动但用量可能上升，Meta 是单价不动、用量直接少四分之一。至于开源：Zuckerberg 周三在 X 上承诺「很快」放出旗舰模型的开放权重版本，但截至 9 月 3 日，Muse Spark 任何版本的权重都还没有公开。Meta 说开放权重在路线图上，未给日期，也未说明会放家族里的哪一个。「说要开源」和「已经开源」之间，差的是一个日期——而在那个日期出现之前，它对你的成本结构没有任何影响。

STORY 04
Claude 的后台电脑操作：成本梯度，写进了架构里
还是 9 月 2 号，Anthropic 让 Claude 的电脑操作能力可以在 Claude Cowork 和 Claude Code 里后台运行。你交代一件事，它在你的桌面上点击、打字、开应用，而你同时干别的。关键在「后台」两个字：以前它要抢你的鼠标键盘，你只能在旁边看；现在你正在打字时它会等，只有任务确实需要占满整个屏幕才会打断，而且先请求许可、一个会话只问一次。桌面版 macOS 与 Windows 都支持，后台执行目前限 macOS 15 及以上，Pro / Max 用户 beta。
真正跟今天主题连上的，是它决定「走哪条路」的顺序：接到任务，Claude 先看有没有对应的连接器（Gmail、Google Drive、Slack——走 API 最快也最稳）；没有连接器，才用浏览器（Claude 桌面内置的，或通过 Claude in Chrome 用你自己的 Chrome）；再不行，才落到像素级的点击。这是一条成本从低到高、可靠性从高到低的阶梯，两者恰好同向。不是「我们支持电脑操作」，而是「电脑操作是最后一条退路」——成本原则一旦想清楚，它会直接长成产品的架构。

STORY 05
麦肯锡的那个数字：三分之一的公司，不买了
最后一条不是发布，是调研，但可能是今天最该记住的。麦肯锡《2026 年 AI 现状》全球调研——5 月 4 日至 6 月 8 日，97 个国家，1719 份回答——其中32% 的组织因为「用 Agent 编码工具自己就能造出来」，放弃了购买至少一个软件产品或功能。拆开看：科技行业 41%，医疗 39%，专业服务与能源材料紧随其后。而在麦肯锡定义的「高绩效者」（那 6%、能把至少 5% 的 EBIT 归因于 AI 的公司）中，接近一半在跳过软件采购，其他人是 31%。越会用 AI 的公司，越不买软件。
这正是前面四条的终点：当一个 Agent 完成一个任务的成本，从「一顿饭」掉到「一杯咖啡」再掉到「几乎不用算」，公司做的就不再是「买 A 还是买 B」，而是「买，还是让 Agent 自己写一个」。这条曲线往下走，会一路走进别人的营收表里。但要给这个数字加两个刹车：第一，麦肯锡问的是「决定不买」，不是「已经造好并且在跑」——决定和交付之间隔着一整个运维周期；第二，你没买，就意味着这东西以后归你养：升级、修 bug、合规、有人离职后谁接手，这些不出现在采购单上，但一分不少。省下的是采购价，接过来的是持有成本。顺带一提，同一份调研里，把 AI 与 EBIT 挂上钩的仍只有 37%，与去年基本持平。

🎙 播客对话 · 大雨 × 小苇
大雨 · 开场
AI 星期五，早上好。这周前三天，四家大厂连着发模型——Anthropic 的 Fable 5.1、Google 的 Gemini 3.8 Flash、Meta 的 Muse Spark 1.3，再加上 Claude 的后台电脑操作。我一条条看完之后，发现它们比的不是同一件事的不同版本，而是同一个数字：干成一件事，到底要花多少钱。
小苇
这不就是降价吗？降价这事我们前两个月已经讲过好几轮了。
大雨
不完全是。降价是「同样的东西，标价低了」。这周发生的是另一回事——它们在改「单位」本身。Anthropic 砍的是缓存读取的价格，Meta 砍的是完成同一个任务要花的 token 数，Google 干脆没动价格、让模型多想一会儿。这三种做法落到你账单上是完全不同的三条曲线。
小苇
那你说的「改单位」，在 Fable 5.1 这条上具体是什么？
大雨
在这行小字里：缓存读取从每百万 token 一美元，降到两毛五——砍掉百分之七十五。这个数字对聊天用户几乎没意义，但对跑 Agent 的人是另一回事。因为一个长跑的 Agent，成本结构跟聊天完全不一样：你跟模型聊天，是不断往上加新内容；Agent 干活是反复回头读同一份上下文——每调用一次工具、每走一步，前面那一大坨系统提示、文件、之前的推理，都得再过一遍。一个跑两小时的任务，同一份上下文可能被读几百次。
小苇
也就是说，这次降价是专门给长任务打的折，不是给所有人打的折。
大雨
一句话说到位了。而且还有个配套的 beta 功能叫「会话中途调节 effort」——你可以在一次会话里随时调高或调低模型在某一步上花多大力气，不用重开一个新会话。这是从「选模型」变成「配预算」：读文件那步省着点，写核心逻辑那步全力开。
小苇
那 Gemini 3.8 Flash 呢？同样的价格分数涨了八点四分，这听起来是今天最实在的一条。
大雨
表面上是。但有两个附注得读。第一，这个价格是有期限的——七毛五和三块七毛五只到今年 12 月 31 号，2027 年 1 月 1 号两个数字都翻倍。第二个附注更有意思：3.8 Flash 不是新的基础模型，它是在 3.7 Flash 上面接着做的，而它拿到那些分数的方式，是让模型「更用力地想」——烧掉更多思考 token。
小苇
等一下。如果输出 token 是按量收费的，那「多想」不就是「多花钱」？
大雨
这正是关键。所以 Google 自己在文档里直说了一句相当诚实的话：如果你的负载是效率优先的，请继续用 3.7 Flash。它其实在提醒你——「同价更强」这句话成不成立，取决于你按什么单位算。按每百万 token 的标价算，它没涨；按每完成一个任务的总花费算，它可能是涨的。这两个单位，今天在整个行业里正在分岔。
小苇
那 Muse Spark 1.3 是哪一种？我想确认一下——它没有降价，对吧？
大雨
没有降价。它降的是你要买的量——跟 1.2 相比，完成同样的任务少用大约百分之二十的工具调用，少烧大约百分之二十五的 token。这是三种降本方式里最干净的一种。至于开源，Aaron Levie 那条推文说得很准：「如果这东西以开放权重发布，会彻底改变美国在开放权重上的竞争格局。」注意他用的是如果——截至 9 月 3 号，Muse Spark 任何版本的权重都还没有公开。
小苇
「说要开源」和「已经开源」之间，差的就是一个日期。那 Claude 那个后台电脑操作，跟前面三条是同一个逻辑吗？我没太看出来。
大雨
你看它是怎么决定「用哪条路」的。接到一个任务，Claude 先看有没有对应的连接器——Gmail、Google Drive、Slack 这些，因为走 API 最快也最稳；没有连接器，它才去用浏览器；再不行，才落到像素级的点击。这是一个成本从低到高的阶梯，而且是可靠性从高到低的阶梯——两者恰好同向。不是「我们支持电脑操作」，而是「电脑操作是最后一条退路」。成本原则一旦想清楚，它会直接长成产品的架构。
小苇
那麦肯锡那个 32%，你怎么看？三分之一的公司决定不买软件了，这个比例有点吓人。
大雨
它正好是前面四条的终点。当一个 Agent 完成一个任务的成本，从「一顿饭」掉到「一杯咖啡」再掉到「几乎不用算」，一家公司做的就不再是「买 A 还是买 B」，而是「买，还是让 Agent 自己写一个」。这条曲线往下走，会一路走进别人的营收表里。
小苇
那我想替 SaaS 公司问一句——这是不是有点太快下结论了？
大雨
问得好，我也想给这个数字加两个刹车。第一，麦肯锡问的是「决定不买」，不是「已经造好并且在跑」。决定和交付之间，隔着一整个运维周期。第二，你没买，就意味着这东西以后归你养——升级、修 bug、合规、有人离职之后谁接手，这些成本不出现在采购单上，但一分不少。省下的是采购价，接过来的是持有成本。而且同一份调研里，把 AI 跟息税前利润挂上钩的只有百分之三十七，跟去年基本持平。这两个数字放在一起，比任何一个单独看都更诚实。
小苇
今天的播客那一期，有没有哪句话让你停了一下的？
大雨
有，而且不是关于写作的。Katie Parrott 讲到她有双相情感障碍，所以她说我们习惯把 AI 当成一种生产性技术——衡量它能产出多少东西；但在她的经验里，AI 同样是一种支持性技术。她拖了三年没预约的家庭医生，是让 Codex 去找了附近收她保险、还接新病人的医生，然后她才终于约上了。她们管这个叫「电脑跑腿」。她说 AI 减少了她生活里的摩擦，让她「更容易当一个人」——我觉得这句比这周所有的基准分都值得记。
小苇
那收个尾吧。今天这五条，你想留下什么？
大雨
一个问题，不是一个结论：你现在能说出，你手上那个 Agent 任务，跑完一次要花多少钱吗？不是每百万 token 多少钱——那是标价；我问的是跑完一整件事的总账。大部分人都答不上来，包括我。而这周四家公司在往三个不同方向优化这个数字。如果你不知道自己的分母是什么，你就没法判断这三条里哪条对你是好消息。这周末挑一个你最常跑的任务，跑一次，把总花费记下来。就一个数字，但它会改变你接下来看每一条发布新闻的方式。

How a Professional Writer Writes With AI（一个职业作者是怎么用 AI 写作的）

Every 驻站作者 Katie Parrott 聊她刚发布的 Compound Writing 插件。「Compound」的定义很干脆：你给 AI 的每一条反馈，都应该回流进系统里，改进下一次的输出——不是「这次帮我改改」，而是「这次的修改意见，变成下次的规则」。插件的编辑环节内置了一堆「评审员」，都是她仰慕的作者的方法论做成的技能：Vonnegut 的八条故事结构原则（从尽可能接近结局的地方开头、每句话都得挣到它的位置、给读者一个可以支持的角色）、Hitchcock 的悬念原理（桌子底下有炸弹，炸了是一秒惊吓；先告诉观众五分钟后会炸，那是五分钟悬念），还有 Sorkin 和写幽默的 Sedaris。她给整个插件的比喻不是「自动写作」，而是健身房：一套让你变成更好的写作者的训练系统。最打动人的一段与写作无关——她讲到自己有双相情感障碍，我们习惯把 AI 当成生产性技术，但在她的经验里它同样是支持性技术：拖了三年没预约的家庭医生，是让 Codex 去找了附近收她保险、还接新病人的医生才终于约上。她的结论：教育和可及性会比以往更重要，因为复利最大的风险，是价值只在一小撮「恰好起步早」的人身上滚。
