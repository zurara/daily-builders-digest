🎙 对话全文 · 大雨 × 小苇
你的用户不是人了
大雨 · DAYU
欢迎来到 Daily Builders Digest，今天是二〇二六年九月十六号，星期三，产品日。我是大雨。
小苇 · XIAOWEI
我是小苇。大雨，你今天开场的表情有点严肃。
大雨 · DAYU
因为我把这周的产品新闻摊在桌上看了一遍，发现它们其实是同一条新闻。Vercel 说，平台上超过一半的部署，是编码 agent 发起的。不是人点的部署按钮，是 agent 点的。
小苇 · XIAOWEI
超过一半。这个数字是什么时候过的线？
大雨 · DAYU
就在最近。Vercel 九月的博客里写得很平静，像在说天气。但你把它翻译成产品语言，意思是：一个做了十年、服务前端开发者的平台，它现在最大的一类用户，不上班、不睡觉、不看你的 onboarding、不点你的 upsell 弹窗。
小苇 · XIAOWEI
也不会在推特上骂你。
大雨 · DAYU
也不会给你五星好评。所以今天这期，我们不按新闻的顺序讲，按一条线讲：当你的用户从人变成 agent，产品的每一层会怎么变形。界面、扩展、边界、约束、主动性，五个层，五条新闻。
01部署按钮后面站着的不是人
大雨 · DAYU
先说 Vercel。九月十四号，Guillermo Rauch 发推说，Steren——Google Cloud Run 的创造者——加入 Vercel，负责 Fluid 这一整个计算产品家族：Functions、Containers、Sandbox、Builds。
小苇 · XIAOWEI
挖一个人来当新闻发，通常是公关动作。这条为什么值得讲？
大雨 · DAYU
因为 Rauch 在那条推里说了一句判断：「Serverless 是云的上一章。Agent 是下一个前沿，而它们需要为它们设计的新计算原语。」这句话如果从别人嘴里说出来是套话，但从一个把 serverless 做成前端默认选项的人嘴里说出来，是在给自己上一代产品写讣告。
📎 来源: Welcoming Steren to Vercel — @rauchg
小苇 · XIAOWEI
「新的计算原语」具体指什么？agent 跑起来跟人跑起来有什么不一样？
大雨 · DAYU
三点不一样。第一，形状不规则。一个 agent 任务可能跑三秒，也可能跑四十分钟，中间大部分时间在等模型返回——空转，但不能被回收。Serverless 的计费和超时模型对这种负载是敌意的。
小苇 · XIAOWEI
按调用次数收钱的模型，碰上「一次调用等二十分钟」就崩了。
大雨 · DAYU
第二，并发和延迟同时重要。传统 web 请求，你优化延迟；批处理任务，你优化吞吐。agent 两个都要。Vercel 把 Fluid 定义成「按工作负载需要的形状，当场造一台机器出来」，就是在回应这个。
小苇 · XIAOWEI
第三呢？
大雨 · DAYU
第三点最产品——agent 会把自己的输出再喂回系统。人写完代码，部署，看一眼，下班。agent 部署完，读日志，发现报错，改代码，再部署。这是一个闭环，闭环的频率不受人的作息限制。所以部署量不是线性增长的，它是循环次数的函数。
小苇 · XIAOWEI
所以「超过一半的部署来自 agent」这个数字，将来只会更高，而且不是慢慢高。
大雨 · DAYU
对。而且这里有一个对产品经理很不舒服的推论：你的用量曲线，将来跟你的用户数解耦了。一个用户可以产生一千个用户的负载。你的定价模型、你的容量规划、你的北极星指标，全都建在「一个人一天能干多少活」这个假设上。这个假设刚刚失效了。
📎 来源: Agentic Infrastructure — Vercel Blog
02Claude Mods：把工具变成可改装的底盘
大雨 · DAYU
第二条，九月十四号，Anthropic 的 Boris Cherny 发推说，Claude Mods 开始上线了。他配了一句：「已经有人用它做了一个在 Claude 里跑的俄罗斯方块。」
小苇 · XIAOWEI
俄罗斯方块。这听起来像玩具。
大雨 · DAYU
玩具是最好的信号。Mods 的技术底子是 TypeScript 的函数钩子——你可以接管界面的渲染和行为。社区第一周做出来的东西包括：把敏感信息在悬停时才显示、把 Mermaid 图直接渲染在对话里、把 diff 面板固定停靠在侧边。
小苇 · XIAOWEI
这些都是很小的需求。
大雨 · DAYU
都是很小、很个人、很难被官方排期排到的需求。而这正是扩展系统存在的全部理由。我想讲的产品判断是这个：一个工具决定开放扩展的时机，暴露了它对自己边界的判断。
小苇 · XIAOWEI
展开说。
大雨 · DAYU
开放太早，核心还在飘，社区插件会把你锁死在一个你还没想清楚的抽象上。开放太晚，用户已经用胶带和脚本在外面自建了一套，你再出官方 API 就是在跟自己的用户抢地盘。Anthropic 选的这个时间点——在 Claude Code 的核心交互稳定之后，在社区的魔改热情还没外溢成生态之前——是一个挺讲究的判断。
小苇 · XIAOWEI
那从 CLI 工具到平台，这一步跨过去之后，产品团队的工作会变吗？
大雨 · DAYU
会变，而且变得很疼。你从「我决定功能」变成「我决定什么是可以被决定的」。你交付的不再是功能，是接缝——hook 点、生命周期、数据契约。这三样东西一旦发出去就很难收回，因为别人的东西建在上面了。
小苇 · XIAOWEI
所以俄罗斯方块其实是在做压力测试。
大雨 · DAYU
俄罗斯方块是在告诉你，这个 API 的表达力超出了设计者的预期。这对平台是好消息，对维护者是长期账单。
📎 来源: Claude Mods are landing — @bcherny
03Cursor 把执行权交出去，只留编排
大雨 · DAYU
第三条。Cursor 做了一件在产品边界上很激进的事：Cloud Agents 现在可以跑在八家不同的 sandbox 上——AWS Lambda、Cloudflare、Coder、Daytona、E2B、Modal、Namespace、Vercel。
小苇 · XIAOWEI
等一下。Cursor 自己不是也有云端执行环境吗？把执行交给别人跑，它自己留什么？
大雨 · DAYU
留编排。规划、任务拆分、状态跟踪、结果收敛，全在 Cursor。至于那段代码具体在谁家机器上跑，Cursor 说：你选。
小苇 · XIAOWEI
这不是把最赚钱的那部分让出去了吗？算力是可以按秒收钱的。
大雨 · DAYU
表面看是。但你反过来想一个问题：企业为什么不敢用云端编码 agent？
小苇 · XIAOWEI
因为代码要出门。内网服务、数据库、密钥，都得让一个外部机器摸到。
大雨 · DAYU
对，这是采购流程里过不去的那一关。Cursor 的判断是：与其花两年时间去建合规、去过审计、去一家家谈 VPC 对接，不如承认执行环境这件事本来就该留在客户手里，我只做他们不会自己做的那部分——编排。
小苇 · XIAOWEI
所以让出算力，换的是进企业的门票。
大雨 · DAYU
换的是「不用问法务」这四个字。而且这里有一个更深的产品判断：在 agent 这一层，护城河不在执行，在编排。 执行是商品，八家供应商价格差不了几倍。编排是你对任务怎么拆、怎么并行、怎么重试、怎么收敛的全部理解，那个是攒出来的。
小苇 · XIAOWEI
但这也意味着如果有人编排做得更好，客户换起来也很容易，因为底下的 sandbox 都是通的。
大雨 · DAYU
这就是这个决定的代价。你把自己暴露在纯能力竞争里，没有锁定可以躲。敢这么做，说明他们对自己的编排有底气。产品上叫「用可替换性换信任」，这是个需要胆子的交易。
📎 来源: Cursor Cloud Agents on customer infrastructure
04给 agent 写规则，就是在做产品设计
大雨 · DAYU
第四条还是 Rauch，同一天。他说：「Agent 的上限，取决于你给它的证明检查器、编译器、类型系统和 linter。」然后他放出了 shadcn/lint——一个专门帮 agent 守住设计系统规则的工具。最后一句是：「Meta：verifier 加 skill，才是新的框架。」
📎 来源: shadcn/lint — @rauchg
小苇 · XIAOWEI
这句我想停一下。「verifier 加 skill 是新的框架」，为什么是框架？框架不是拿来复用代码的吗？
大雨 · DAYU
框架的本质从来不是复用，是限制。React 值钱不是因为它替你写了 DOM 操作，是因为它不让你随便碰 DOM。Rails 值钱不是因为它生成了几个文件，是因为它替你把一百个决定拍死了。框架是一套「你不能这样做」的集合。
小苇 · XIAOWEI
那对 agent 来说……
大雨 · DAYU
对 agent 来说，「不能这样做」得写成它能撞上的东西。人可以读文档、看规范、被 code review 教育。agent 不行。agent 只认一件事：跑一下，红了，改。所以你的设计规范如果只是 Figma 里的一页说明，agent 看不见；你得把它变成一个会报错的 linter，agent 才碰得到。
小苇 · XIAOWEI
所以 shadcn/lint 干的事，是把设计系统从文档变成了报错。
大雨 · DAYU
一句话说完了。而这对产品团队的含义是——你写的规范，从今天起要分成两类：给人读的，和给 agent 撞的。 后面这类如果不存在，agent 就会把你的设计系统慢慢磨平，一次一个组件，谁也不会发现。
小苇 · XIAOWEI
这个比我想的严重。因为磨平是没有报警的。
大雨 · DAYU
没有报警，只有半年后某次设计走查，发现全站有十七种按钮。
05Gemini 的主动性，和一个被低估的内测方法
大雨 · DAYU
第五条稍微软一点，但很有意思。九月八号，Google 把 Gemini 的 Daily Brief 在美国免费开放——这功能原本是 AI Plus、Pro、Ultra 付费用户才有的。
小苇 · XIAOWEI
Daily Brief 是什么？
大雨 · DAYU
它由 Personal Intelligence 驱动，会去读你的 Gmail、日历、连接的应用，还有你以前的 Gemini 对话，每天早上给你一份：「Top of mind」放有截止时间的事，「FYI」放带日期的其他事，「Looking ahead」放长期目标和建议的下一步。
小苇 · XIAOWEI
也就是不用你问，它自己推给你。
大雨 · DAYU
这是产品上最难的一类东西：主动型产品。被动产品你只要答得准就行，用户问了才有你。主动型产品你得替用户判断「这件事值不值得打断他」——判断错了不是没用，是讨厌。
小苇 · XIAOWEI
然后把它免费了。
大雨 · DAYU
把一个付费功能免费，通常是两种信号：要么它没能撑起付费转化，要么它是留存钩子，值得用它去换日活。Daily Brief 这种每天早上都会打开一次的东西，明显是后者。
小苇 · XIAOWEI
那另外一半新闻呢？你刚才说这条跟一条推特有关。
大雨 · DAYU
对，九月十四号，Google 的 Josh Woodward 发推说：两个月前他们建了一个 Gemini 重度用户群，测早期功能，两个月测了二十多个特性；现在新一批人正在拿到 Daily Brief 和 Personal Intelligence 的下一步权限。
📎 来源: Gemini power user group — @joshwoodward
小苇 · XIAOWEI
二十多个特性，两个月。这个节奏挺吓人的。
大雨 · DAYU
吓人的不是节奏，是他们选择了一个很老派的方法。在一个什么都能拿去做 A/B 测试、什么都有埋点的公司，他们建了一个几百人的群，手动地、一批一批地放人进来。
小苇 · XIAOWEI
为什么不直接 A/B？
大雨 · DAYU
因为 A/B 只能告诉你哪个数字更高，不能告诉你为什么。尤其是主动型产品——你想知道的是「今天早上这条推送，你当时在干嘛，你看完什么感觉」。这个问题埋点答不了，只有人能答。
小苇 · XIAOWEI
所以最先进的 AI 团队，在用最原始的办法做用户研究。
大雨 · DAYU
而且是刻意的。我觉得这是今天最值得记的一条：当产品的判断标准从「有没有用」变成「合不合时宜」，你就必须回到跟人说话。
今日一个不太好听的注脚
小苇 · XIAOWEI
今天五条都是「agent 正在变成一等公民」。有没有反面？
大雨 · DAYU
有两条，都值得贴在墙上。第一条来自 Box 的 CEO Aaron Levie，九月十四号：「在一个 agent 使用我们系统的频率是人的一百倍的世界里，保护企业数据将是二十一世纪最复杂的安全和治理挑战之一。」
小苇 · XIAOWEI
一百倍。
大雨 · DAYU
他后面还有一句更狠的：安全和生产力在 AI 世界里是绑死的——如果你给 agent 的信息访问权太宽松，你就没办法真正控制和保护你的数据。翻译成产品语言就是：权限设计从今天起是核心功能，不是合规附件。
📎 来源: On agent data governance — @levie
小苇 · XIAOWEI
第二条呢？
大雨 · DAYU
Gartner 的预测：到二〇二七年，超过四成的 agentic AI 项目会被砍掉。原因写得很朴素——成本失控、价值不清、控制不足。
小苇 · XIAOWEI
这跟我们今天讲的五条不矛盾吗？
大雨 · DAYU
一点都不矛盾。今天这五条讲的都是基础设施层：计算形状、扩展点、执行边界、约束机制、主动推送。Gartner 砍掉的那四成，是应用层里那些「我们也要做个 agent」的项目。基建在夯实，同时大量应用在死掉——这两件事在每一次平台转移里都同时发生过。
小苇 · XIAOWEI
上一次是移动。
大雨 · DAYU
上一次是移动。App Store 头两年也有一大堆「我们也要做个 app」的项目死掉，同时 iOS 的相机 API、推送、定位在一层层夯实。死掉的是找不到「为什么非得是这个形态」的那些。
关注建造者
大雨 · DAYU
今天的建造者动态，我挑了四条，都在今天的主线上。
小苇 · XIAOWEI
那我们收尾吧。今天这五条，你要是只留一句给听的人？
大雨 · DAYU
我留一个问题，比较具体，今天下班前就能问自己：你产品里那些「只有人才懂」的规则，现在写在哪？ 是写在 Figma 的一页说明里、写在新人文档里、写在某个资深同事的脑子里，还是写在一个会报错的地方？
小苇 · XIAOWEI
因为写在前三个地方的，agent 都读不到。
大雨 · DAYU
读不到，也不会告诉你它读不到。它只会静静地，把你的东西磨平。
小苇 · XIAOWEI
那我们明天见。明天是星期四，健康日。
大雨 · DAYU
明天见。
