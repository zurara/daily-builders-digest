🎙 对话全文 · 大雨 × 小苇
大雨 · 开场
Product 星期三，早上好。今天这期我想从一个很朴素的问题开始：如果你是一个产品负责人，你今年最花时间的那件事，和三年前是不是同一件？
小苇
我猜不是。
大雨
不是。今天我挑的四条，表面上八竿子打不着——苹果今天在库比蒂诺开发布会，OpenAI 的新模型在往所有人账号里推，Vercel 开源了一个给 agent 用的浏览器，还有一堆投资人和 CEO 在推特上吵「以后到底缺什么」。但它们说的是同一件事：产品的瓶颈搬家了。
小苇
从哪搬到哪？
大雨
从「能不能做出来」，搬到了两头。一头是前面——做什么。另一头是后面——做完了谁来验。中间那段「把它做出来」，正在变成整条链上最便宜的一段。
小苇
那今天苹果那场发布会算哪一头？
大雨
苹果那场特别有意思，它是唯一一条还卡在中间那段的新闻。折叠屏这个东西，难点百分之百在「能不能做出来」，而且它逼着苹果公开做了几个很痛的减法。我想先讲它，因为它正好是个对照组——提醒你产品的本质从来不是功能表，是取舍表。
小苇
那顺序是？
大雨
四条。第一条，苹果今天上午十点开「Surprise and Shine」，新 CEO John Ternus 的第一场 iPhone 发布会，主角是九年来第一个新形态。第二条，GPT-6 Astra 上周四发布，这两天开始往 Plus、Pro、企业版和 API 全量推，Codex 那边已经把它设成默认。第三条，Vercel 的 Rauch 在推 agent-browser，他自己那句话我原封不动念一遍：「软件工程新的瓶颈是 review、测试和 QA」。第四条不是新闻，是一堆人这周同时得出的一个结论——建造变便宜之后，「建什么」成了稀缺品。
小苇
听起来第一条和后面三条不在一个世界里。
大雨
对，所以才值得放在一起听。
01

九年来第一个新形态，和它砍掉的三样东西

Apple「Surprise and Shine」· iPhone 18 Pro / Pro Max / iPhone Ultra · A20 Pro 2nm · 新 CEO John Ternus 首场
大雨
苹果今天上午十点在 Apple Park，标语是「Surprise and Shine」。要发的是 iPhone 18 Pro、18 Pro Max，还有那台传了两年的折叠机，外面猜它叫 iPhone Ultra。
小苇
今年没有标准版 iPhone 18？
大雨
没有。苹果把便宜那档挪到了 2027 年春天。所以今年秋天这场，从产品线上说是一场「全 Pro 发布会」。三台机器都用 A20 Pro，二纳米。
小苇
那折叠这台，值得讲的是什么？
大雨
值得讲的不是它能折，是它为了能折砍了什么。目前的说法：合起来大概 5.5 英寸，展开大概 7.6 英寸，书本式，展开之后是宽大于高，用起来接近一台小 iPad。因为太薄，它用 Touch ID，不用 Face ID；而且没有长焦镜头。
小苇
等一下。Face ID 是苹果 2017 年 iPhone X 那次立起来的招牌，长焦是这几年 Pro 系列最主要的加价理由。这台机器把这两样都拿掉了？
大雨
都拿掉了。而且这台大概率是三台里最贵的。
小苇
那它凭什么卖？
大雨
凭形态本身。这就是我说它是对照组的原因。过去八九年，手机这个品类的产品逻辑是加法——加镜头、加刷新率、加芯片、加 AI 功能。加法的好处是安全，坏处是你看不出来今年和去年有什么不一样。折叠这一步是减法换形态：我拿走你两个你已经习惯的东西，换给你一块能变大的屏。
小苇
那这个交换成不成立，谁说了算？
大雨
用户。而且这种交换特别难做用户调研，因为你问「你愿不愿意用 Face ID 换一块大屏」，没人答得准，人要摸到才知道。这也是硬件产品和软件产品最不一样的地方——软件可以先发一个开关，看多少人打开；硬件是一次性押注，押完等一年。
小苇
这是 Ternus 上任之后第一场。压力应该不小。
大雨
不小，而且外面已经在提前泼冷水了。KeyBanc 上周一发了个研究备忘，直接说这场发布会有可能变成股价的负面催化剂——理由不是产品不好，是内存涨价之后苹果只有两条路：全线涨价，或者自己吃掉毛利。两条路投资人都不爱看。
小苇
所以一场发布会，产品在讲取舍，市场在算成本。
大雨
这是所有做硬件的人都熟悉的那种撕扯。除了 iPhone，今天还会有 Apple Watch Series 12 和 Ultra 4，可能有传了很久的家庭中枢，还会公布 iOS 27、macOS Golden Gate 这些系统的正式发布日期。
小苇
那我们今天讲这条，产品人该带走什么？
大雨
一句话：你的产品文档里，「砍掉了什么」那一栏如果永远是空的，那你做的很可能不是产品，是功能列表。
02

Astra 全量推开：模型不再是聊天框，是交付物

GPT-6 Astra · 09-03 发布 · Daybreak Access → Plus / Pro / Business / Enterprise / API · Codex 默认模型
大雨
第二条。GPT-6 Astra，OpenAI 上周四九月三号发的，这两天开始铺开。前天 OpenAI Codex 那边的 Thibault Sottiaux 发了一条，就六个字：「我们回来了」。一万四千个赞。第二天他又发：「所有人都重置了，这周好好用 Astra。」
小苇
「重置」是指用量额度？
大雨
是额度。但我更在意他后面那条——他说他正在看一份二十八页的 deck，里面是 Codex 自己在记录这一轮的每一项发布。这个细节比模型跑分有意思：这份 deck 不是产品经理做的，是工具自己攒的。
小苇
Astra 这次改的是什么？
大雨
官方口径是编程、研究、电脑操作，和复杂多步骤的活。但对产品人最有信号的是这一句：它能按照你自己的模板和要求，生成文档、表格、演示文稿，而且你中途加需求、改方向，它跟着改。
小苇
这句话为什么重要？听起来像个办公功能。
大雨
因为它把产品形态往前推了一格。第一代 AI 产品的形态是聊天框，你得到的是一段文字，剩下的活你自己干。这一句说的是：你得到的是一个交付物，而且这个交付物长得像你们公司的东西。中间那段「把答案变成公司要的格式」——那正好是很多人一天里最耗时、最没价值感的一段。
小苇
但「按模板」这件事，工具类产品吹了很多年了。
大雨
吹了很多年，而且大部分翻车在同一个地方：模板对了，判断不对。所以我不打算今天就下结论。而且推广节奏本身也说明它还没稳——第一批只给 Daybreak Access 里的少数机构，然后才是 Plus、Pro、Business、Enterprise 和 API，一路铺到 Azure 和 Bedrock。Codex 那边把它设成了默认模型。
小苇
有没有反面的声音？
大雨
有，而且我觉得很值得听。Peter Yang 前天发了一条，说不知道是不是自己哪里搞错了，但 Astra 在自动触发他写的 skill、以及遵守 skill 里的指令这两件事上，表现比之前差。这条只有十七个赞，被那条一万四千赞的「我们回来了」淹掉了。
小苇
十七对一万四。
大雨
这就是为什么产品人要自己去翻小号发言。「更强的模型」和「更听话的模型」不是一回事，而且升级的时候，后者经常是被牺牲掉的那个。如果你的产品建在别人的模型上，每一次模型升级对你来说都是一次没经过你同意的发版。
03

新瓶颈是 review：Vercel 把 QA 做成了产品

Vercel agent-browser · 开源 · npm 周下载 10 万+ · 省 82% context · Rauch OSS Grants v2
大雨
第三条我最想讲。Vercel 的 CEO Guillermo Rauch 昨天发了一条推，介绍他们的 agent-browser 加了高质量录屏。这条本身不算大新闻，但他那句解释是这周最值钱的一句话。
小苇
哪句？
大雨
他说：我们在把软件工程里那个「新的瓶颈」自动化，这个新瓶颈是 review、测试和 QA。
小苇
这句话的分量在哪？
大雨
在于它是从写代码那一头说出来的。过去两三年，所有工具都在解决同一个问题：怎么让写代码更快。现在写代码这一段真的变快了之后，卡住的地方自然往后移——移到了「你怎么知道它写对了」。
小苇
那 agent-browser 具体是个什么东西？
大雨
一个命令行的浏览器自动化工具，专门给 agent 用，Vercel Labs 开源的。npm 上现在每周十万多次下载，一天能发好几个版本。它跟传统方案最实在的差别是省 context：有人做过对比，同样跑六个测试，Playwright MCP 大概吃掉三万一千个字符，agent-browser 大概五千五。
小苇
差不多省了八成。
大雨
省八成的意思是，同样的上下文预算，agent 能多跑五六倍的测试。这个数字我建议你换个角度理解——它说明「验证」这件事本身，现在开始按 token 计价了。以前 QA 的成本单位是人天，现在多了一个单位是上下文。
小苇
那这对产品设计有什么影响？
大雨
影响很大。如果验证按 token 算，那「什么值得验」就成了一个要设计的东西。全量回归跑一遍很爽，但很贵；只跑关键路径很便宜，但会漏。这个取舍以前藏在测试团队内部，现在会被摆到产品决策桌上来。
小苇
我看到 Peter Steinberger 那条也是这个话题。
大雨
对，他那条特别刺。他说他给一个上游开源项目提了个 PR，对方要求改几个小地方。他的原话是：这个流程到底还有什么意义？你已经写好了提示词，为什么还要我去戳一下我的 agent，然后你的 agent 才来合并？
小苇
听着像抱怨，但底下是个真问题。
大雨
是个很真的问题。我们现在整套协作流程——PR、review、comment、approve——是为「人类写代码、人类读代码」设计的。现在两头都换成了 agent，中间那套礼节还留着。它可能是冗余，也可能是唯一还拦得住事故的东西。这个我不知道答案，但今年谁想清楚了谁做出下一个开发者工具。
小苇
Rauch 这周还干了别的事？
大雨
他宣布了第二轮开源赞助，给三十五个贡献者各一千美元，两个主题。第一个主题叫「Agent skills & tools」，他那句话我念一下：skill 现在本身就是一种有价值的软件。第二个是本地 AI。
小苇
「skill 是一种软件」——这句话是认真的吗？
大雨
我觉得是认真的，而且它对产品人是个新品类信号。一个 skill 没有界面、没有登录、没有定价页，但它有版本、有依赖、有兼容性问题、会被别人 fork。它是软件该有的所有特征，除了长得不像软件。
04

建造变便宜之后，稀缺的是「建什么」

Nikunj Kothari × Amjad Masad × Aaron Levie · 产能上去了，判断力没上去
大雨
最后一条不是新闻，是一个这周在好几个人嘴里同时冒出来的判断。FPV Ventures 的 Nikunj Kothari 前天写：越来越多人得出同一个结论——建造变容易之后，「建什么」成了那个重要的瓶颈。
小苇
这句话有点像正确的废话。
大雨
单独看是。但把它跟另外两条并排看就不废了。Replit 的 Amjad Masad 前天说，他不认为我们到了 AGI，但我们现在手上这个东西，在功能上已经和 AGI 分不出来了——因为我们有了一个不会腻、不会累的程序员，所以任何能被表述成编程问题的问题，基本上等于解决了。
小苇
关键在「能被表述成编程问题」这半句。
大雨
对，这半句就是产品人的活。把一个模糊的、有人味的、互相矛盾的需求，翻译成一个能被表述成编程问题的东西——这一步以前叫写 PRD，现在它突然变成了整条链上唯一没被压缩的一步。
小苇
那 Box 的 Aaron Levie 那条呢？我看他说 AI 对就业的影响和大家预测的正好相反。
大雨
他的论点是这样的：AI 目前进入的那些领域，需求本身不是固定的。翻译一下——不是「本来要做一百件事，现在机器做八十件，所以裁八十个人」，而是「本来只能做一百件，现在能做一千件」。而且他强调 agent 还是需要人来操作和盯着，才能真正产出价值。
小苇
那这三条串起来是什么？
大雨
串起来是：产能上去了，判断力没上去。以前一个团队一个季度只能做三个东西，「做什么」这个问题被产能自动帮你回答了一大半——反正也做不完，挑最紧急的三个就行。现在能做三十个，那这个问题第一次真的落到你头上。
小苇
听起来产品经理的活变多了。
大雨
变多了，但也变纯了。以前很大一部分工作其实是排期、催进度、协调资源，是在跟产能不足搏斗。那部分正在缩水。剩下的是最难也最像本职的那部分——判断哪个值得做，和判断这个做出来的东西够不够好。前一个是入口的判断，后一个是出口的判断。今天四条新闻，第一条讲的是入口的取舍，第三条讲的是出口的验证，中间那段谁都在帮你做。
小苇
那如果一个人恰好只擅长中间那段呢？
大雨
那就往两头挪。这是我今天最想说的一句，不太好听但是真话。

关注建造者 · 今日播客

AI & I by Every · 2026-08-26 · Walleye CEO Will · $10B AUM · 400 人
大雨
今天的播客选的是 Every 的《AI & I》，八月底那期，嘉宾是 Walleye 的 CEO Will，管着接近一百亿美元的对冲基金，四百人。这期开头他念了自己给全公司写的一封信，第一句是：用 ChatGPT 不算作弊。
小苇
「不算作弊」——这个说法很有意思，说明公司里真的有人这么觉得。
大雨
他后面那句更直接：这是个从学校里带出来的、放在这儿不适用的观念。作为一家对冲基金，我们应该为了「因为不肯用能让我们更快更聪明的工具，把钱留在桌上」而感到羞耻。
小苇
他做了什么具体的事？
大雨
一件事：全公司每一个人，不管什么部门、技术不技术，强制培训到一个基准的熟练度。他讲了为什么强制——因为大家其实是焦虑的，焦虑「这对我的工作意味着什么」「我该学什么」。公司站出来说我们会培训你、工具会给你，但你得自己学，这本身就是一种回应。
小苇
这跟今天的主题对得上。
大雨
对得很上。这是一个组织内部的产品问题：不是买不买工具，是怎么让四百个不一样的人真的用起来。他还有个比喻我很喜欢——他说他小时候最喜欢的动画是《石中剑》，里面的梅林是倒着活的，能瞥见未来，但看不见中间那些步骤。他说他现在就是这个状态：五年后这行会长什么样，他几乎不可能看错；但从这儿走到那儿的每一步，是糊的。
小苇
那种状态挺难受的。
大雨
挺难受，但这就是今年做产品的默认状态。终点比路径清楚。
✕

收尾 · 今天就能做的一个练习

砍掉了什么 · 怎么知道它对了
小苇
今天这期收一下？
大雨
收一下。四条新闻，一条线：瓶颈搬家了。苹果今天在硬件上做一次减法换形态，提醒我们产品的本质是取舍表不是功能表；Astra 把交付物变成了模型的输出，中间那段格式化的活在消失；Vercel 把 review 和 QA 当成新瓶颈来做产品；剩下那批人在说，建造变便宜之后稀缺的是判断。
小苇
