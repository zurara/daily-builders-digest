◈ 七千台这个数字，到底在说什么
现在卖的不是生产力，是数据集
01基线。IFR 首次把人形机器人单列统计，2025 年全球约 7,000 台，口径为工业与专业服务用途。这是新开的一栏，没有可比历史数据。
02用途。IFR 指出，其中很多由研究机构和企业购入，用于采集真实世界数据训练 AI 模型，而不是投入生产作业。
03比例尺。同期参照：2024 年全球工业机器人装机约 542,000 台，专业服务机器人约 199,000 台。人形与工业相差约 77 倍。
04预测。美国银行全球研究预计 2026 年出货 90,000 台、2030 年 120 万台。但它与 IFR 统计口径不同（出货 vs 售出），两个数字不能直接相除。
05因此。数字本身不重要，重要的是靠什么方式实现：如果 90,000 台里多数仍流向数据采集，那扩张的是训练集，不是产业。

◈ 监管在核查的，正好是同一笔钱

China IPO Slowdown · 路透 2026-09-21
不是禁令，是窗口指导

触发点。宇树科技在上海上市当日股价一度涨超 5 倍，随后自高点回落 55%。

状态。监管以非正式指导压住了部分人形机器人公司的上市。一位知情人士形容该板块 IPO 「基本冻结」，另一位则称并无正式禁令。至少 6 家公司在排队，包括云深处、自变量机器人、智元机器人。

核查对象。来自地方政府支持项目的收入——机器人数据采集中心与合资公司。这类项目中，地方政府常出资占初始投资的 80%–90%。

问题。这笔收入能撑起估值、达到上市门槛，但它反映的是独立客户的真实需求吗？有接近投资人的人士估计，若剔除数据采集中心收入，部分公司估值可能下跌 60%–70%；一级市场已有项目被削价 30%–50%。

但不是退潮。报道引述的高管与投资人称，重心转向实际部署、订单量、以及能否把技术演示变成商业产品。

◈ 判断这个行业走出「造数据集」阶段的三个信号
都不需要内部消息
下次读一家人形机器人公司的材料时，按顺序看这三件事。
收入结构 复购 服务合同
一、收入结构。营收中来自政府支持项目、数据采集中心、关联方交易的比例。这个比例下降，说明独立客户在变多。

二、复购。数据采集是一次性采购，生产部署才会复购。同样是卖出几千台，「几千个客户各买一台」和「几十个客户各买几十台」是两个完全不同的行业。

三、服务合同。当客户愿意按服务付费（如 LaaS）而不是买设备，说明可靠性已经到了能写进合同的程度。卖设备可以卖给期待，卖服务只能卖给能力。

◈ 今日脚本 · 大雨 × 小苇

◈ 开场：一个把所有故事钉在地上的数字

大雨
周二好，欢迎回到每日快报。今天是九月二十二号，机器人星期二。昨天，国际机器人联合会——就是 IFR，这个机构每年统计全世界装了多少台工业机器人，做了几十年——第一次把人形机器人单独拉出来统计了一次。结果出来了：二〇二五年，全球一共卖出去七千台。
小苇
七千台。
大雨
七千台。
小苇
我需要缓一下。因为同一个行业，今年上半年融资是两百三十亿美元。
大雨
对。所以今天这一期，其实就是围着这个数字转。昨天一天之内出了四条新闻，看上去完全不相干：IFR 的统计、中国监管在给人形机器人 IPO 踩刹车、法拉第未来一口气发了九款机器人、还有一家韩国公司把机器人基础模型塞进了真实的物流仓库。但你把七千这个数字摆在中间，这四条新闻立刻就串起来了。
小苇
串成什么？
大雨
串成一个问题：这个行业正在花的钱，和这个行业正在卖出去的东西，中间差了多少个数量级，以及这个差距靠什么填上。

◈ 第一条：IFR 数了一遍，七千台，而且买家大多不是来干活的

大雨
先把这个数字讲清楚。IFR 说，二〇二五年全球卖出约七千台人形机器人，统计口径是工业和专业服务用途。这是 IFR 第一次收集人形机器人的数据——它之前一直在数工业机器人和专业服务机器人，人形是新加进来的一栏。
小苇
所以这个基线本身是新的，之前没有可比的历史数据。
大雨
对，这一点得说在前面。但更值得注意的是另一句话：这七千台里，很多是研究机构和公司买去采集真实世界数据、训练 AI 模型的，不是买去干活的。
小苇
等一下。那意思是，人形机器人目前最主要的用途，是给人形机器人生产训练数据？
大雨
这句话听起来像绕口令，但它就是现在的状态。你可以理解成，这七千台里相当一部分是数据采集设备，不是生产设备。它们的产出物是数据集，不是拧好的螺丝或者分拣好的包裹。

📎 来源: Global humanoid robot sales reached about 7,000 in 2025: IFR

小苇
我想找个参照系。七千台，跟别的机器人比是什么概念？
大雨
好，参照系很有说服力。二〇二四年，全球装了大约五十四万两千台工业机器人。专业服务机器人——就是做运输、做接待、做清洁那些——那一年卖了大约十九万九千台。
小苇
所以人形是七千，工业是五十四万。差了七十几倍。
大雨
差了大概七十七倍。而且工业机器人那五十四万台，每一台都是真的在生产线上干活的，没有哪家厂买一台六轴机械臂回去"采集数据"。
小苇
那另一边，预测是多少？
大雨
美国银行全球研究预测，今年，也就是二〇二六年，人形机器人出货量会到九万台，到二〇三〇年是一百二十万台。九万台，差不多是 IFR 二〇二五年统计数的十三倍。
小苇
一年十三倍。
大雨
一年十三倍。不过这里要提醒一句，IFR 和美国银行的统计口径不一样——一个数的是"卖出"，一个数的是"出货"，而且覆盖范围也不完全重合。所以严格讲，这两个数字不能直接相除。但即使把口径差异都让出去，剩下的增速也还是很陡。
小苇
那这个十三倍，你信吗？
大雨
我的看法是，这个数字本身不重要，重要的是它靠什么方式实现。如果九万台里有七万台还是卖给实验室采集数据的，那这就不是一个产业在扩张，是一个训练集在扩张。如果九万台里有六万台真的进了工厂、仓库、门店，那才是另一回事。这个区分，到年底看财报就知道了。

◈ 第二条：中国监管在给人形机器人 IPO 踩刹车

小苇
那我们说第二条。昨天路透社的报道是，中国监管在收紧人形机器人公司的上市。
大雨
对。措辞很有意思——不是正式禁令，是窗口指导。有知情人士形容这个板块的 IPO 活动"基本冻结了"，另一位则说并没有正式的禁止。目前至少有六家中国人形机器人公司在准备上市，包括云深处、自变量机器人、还有智元机器人。
小苇
触发点是什么？
大雨
宇树在上海上市那天的走势。股价一度涨了五倍多，然后从最高点跌了百分之五十五。
小苇
那这个波动本身，监管在担心什么？
大雨
监管关心的不是股价波动，是波动背后那笔收入是怎么来的。他们在查的是一类特定的营收：来自地方政府支持的项目——机器人数据采集中心，还有各种合资公司。
小苇
数据采集中心。又是数据采集中心。
大雨
你抓到点子上了。这正是我要说的——这条新闻和第一条新闻，讲的是同一件事的两头。 IFR 说七千台里很多是买去采数据的；中国监管说，卖给这些数据采集中心的收入，得重新看一看。
小苇
重新看什么？
大雨
看这些项目里，地方政府经常出到初始投资的百分之八十到九十。这样的项目确实能让公司产生营收、撑住一级市场估值、达到上市的财务门槛。但监管在问的问题是：这笔收入，反映的是独立客户的真实需求吗？

📎 来源: China Slows Humanoid Robot IPO Push as Regulators Scrutinize Valuations

小苇
如果把这部分收入剔掉，会怎么样？
大雨
有接近人形机器人投资人的人士估计，某些公司的估值可能会下跌百分之六十到七十。一级市场上，已经有一些机器人项目的估值被砍了百分之三十到五十。
小苇
那这算是行业退潮吗？
大雨
报道里引述的高管和投资人明确说不是。他们的说法是，重心变了——现在投资人看的是实际部署、订单量、以及能不能把技术演示变成真的卖得出去的产品。
大雨
我觉得这句话是今天最值得记住的一句。技术演示和商业产品之间那道坎，以前可以用融资跨过去，现在开始要用订单跨了。
小苇
有一个细节我想补一下。上个月有一位行业内的 CEO——梅卡曼德的邵天兰——在微信上公开说，一些估值很高的具身智能公司，在冲 IPO 的过程中依赖数据采集中心、关联方交易这类安排。
大雨
对，这条是公开的指控，不是监管文件。但它和监管的关注点撞在一起了，这就是为什么它有分量。

◈ 第三条：法拉第未来一口气发九款机器人，价格从九千九到十三万八

小苇
第三条画风就完全不一样了。
大雨
完全不一样。九月二十一号，法拉第未来——对，就是那个造车的法拉第未来——发布了五个型号、九种配置的具身智能机器人，人形和四足都有。

具体是什么？
大雨
我列一下，因为这个价格谱系本身就是信息：<br>· FF All-New Futurist：全尺寸人形，五十一个主动自由度，换上灵巧手可以到七十一个。一千一百五十二瓦时双电池，标准工况下大约八小时，支持自主充电。Ultra 版用英伟达 Jetson Thor，算力七百 TOPS。标准版八万九千九百美元起，Ultra 版十二万九千九百美元。<br>· FF Master Mini：大约九十五厘米高，十九点五公斤，面向教育、娱乐和机器人竞赛。三个版本算力分别是 48、117、200 TOPS，价格九千九百九十到一万七千九百九十美元。<br>· FX Aegis Hyper：大型工业四足，用于极端环境和高风险作业，可以挂热成像、气体检测、三维扫描、通信设备。十三万七千九百美元起。<br>· FX Aegis Mega：中型轮足工业机器人，最大负载五十公斤，能爬二十五厘米台阶，跨越八十厘米障碍，空载至少五小时，电池可热插拔。七万四千九百九十美元起。<br>· FX Aegis Classic Ultra-W：约二十二公斤的轮足机器人，做安防和陪伴，支持多机协同。一万二千九百九十美元。
小苇
这个跨度太大了。从九千九到十三万八，中间差了十四倍。这不像一个产品线，像一个货架。
大雨
它本来就是一个货架。法拉第说，整个 EAI Robot World 产品组合现在覆盖人形、四足和移动操作机器人，五个产品系列、十一个型号、二十四款产品。而且全部现货发售，FF.com、亚马逊、RobotShop 三个渠道都能买，还能租。
小苇
那这个策略背后的想法是什么？押注哪种形态会赢吗？
大雨
恰恰相反。创始人贾跃亭在公告里援引了李飞飞的观点——多种机器人形态会在同一个生态里共存。他的原话是，这些形态不只覆盖更多任务，还能从多样的场景和交互中产生真实世界数据，这些数据再通过他们的 EAI Data Factory 去训练 EAI Brain，做技能开发和设备迭代。
小苇
等一下。又是数据。
大雨
今天第三次了。IFR 说买家是为了采数据；中国监管在查数据采集中心的收入；法拉第把数据工厂写进了产品战略的核心。
小苇
所以整个行业现在真正在交易的东西，是数据？
大雨
我觉得可以这么说：现在这个行业里，机器人本体更像是数据采集的终端，而不是生产资料。这不一定是坏事——这确实是训练具身智能模型的必经之路。但这意味着，你在读一家人形机器人公司的营收时，得先问一句：这笔钱是买机器人去干活的，还是买机器人去产生数据的。

小苇
那这九款里，你觉得哪款最有意思？
大雨
Master Mini，九千九百九十美元那款。因为它是唯一一款价格进入了学校采购单的人形机器人。法拉第给它配的是 Blockly、Python、ROS 课程、师资培训、竞赛体系和课堂管理工具。
小苇
这听上去不像卖机器人，像卖教材。
大雨
是卖教材。而且这条路的逻辑很实在：一台九千九的机器人，一间教室能买；一台八万九的，只有实验室能买。谁在教室里，谁就在培养十年后的工程师。

◈ 第四条：RLWRLD 把机器人基础模型开进了真实仓库

小苇
最后一条。
大雨
这一条我觉得是四条里最"无聊"的，也是最值得看的。韩国的 RLWRLD 和 CJ 大韩通运——韩国最大的物流公司之一——扩大了合作，签了谅解备忘录，要联合开发物流用的机器人基础模型，他们叫 RFM，Robotics Foundation Model。
小苇
谅解备忘录。这个词听上去分量不重。
大雨
分量不在词上，在做法上。RLWRLD 的 CEO 柳正熙说了一句我觉得该念一遍的话："要让物理 AI 真正转化为产业里可见的生产力提升，关键是走出实验室验证，从真实运营中积累数据，再把这些数据反馈回去，让 AI 智能持续改进。"
小苇
这句话几乎是在回应我们前面聊的所有东西。
大雨
对。前面三条讲的都是为了采数据而采数据——买机器人去采数据、开数据中心去采数据、建数据工厂去采数据。而这一条讲的是在真实业务里干活，干活本身产生数据。
小苇
这个区别有多大？
大雨
区别在于，数据的分布不一样。实验室里摆拍出来的抓取数据，和仓库里真实包裹的抓取数据，长得完全不是一回事。物流现场的东西大小不一、形状不一、材质不一，工况还一直在变。这类任务要求机器人调整动作，而不是执行预设的动作序列。
大雨
RLWRLD 在做的 RLDX-1 模型，就是冲这类任务去的——用视觉和其他传感器数据理解环境，再决定怎么动，重点放在工业环境里的操作和灵巧性。
小苇
那落地路径是什么？
大雨
分步走。先挑几个物流环节做概念验证，在真实工况里测机器人任务；有结果了再扩展到更多环节，最后往 LaaS 走——物流即服务，企业不用自建物流中心、运输网络和自动化系统，直接把物流能力当服务买。

📎 来源: RLWRLD, CJ Logistics Expand Robotics Partnership for Logistics Automation

小苇
我注意到他们没提"人形"两个字。
大雨
报道里提了一句 CJ 大韩通运一直在扩大 AI 自动化的使用，包括人形机器人。但你说得对——整条新闻的主角是模型，不是形态。这跟法拉第那条正好是一个镜像：法拉第在铺形态，RLWRLD 在铺模型。

◈ 把四条串起来：七千台这个数字到底说明了什么

小苇
那我们回到开头那个数字。七千台，你最后的判断是什么？
大雨
我先说一个我不会做的判断：我不会说这是泡沫。七千台这个数字之所以小，不是因为技术不行，是因为这个行业现在处在一个特定的阶段——它还在造数据集，不是在卖生产力。
小苇
那怎么判断它走出这个阶段了？
大雨
我给三个可观察的信号，都不需要内部消息：<br>第一，看收入结构。一家公司的营收里，来自政府支持项目、数据采集中心、关联方交易的比例是多少。这个比例下降，说明独立客户在变多。这一点中国监管现在正在替我们查。<br>第二，看复购。一个客户买了第一台之后，有没有买第二台、第十台。数据采集是一次性采购，生产部署才会复购。宇树那种一次卖几千台的量，得看是几千个客户各买一台，还是几十个客户各买几十台——这两种完全不是一个行业。<br>第三，看有没有人签服务合同。RLWRLD 那条里的 LaaS 就是这个意思。当客户愿意按服务付费而不是买设备的时候，说明这个东西的可靠性到了能写进合同的程度。卖设备可以卖给期待，卖服务只能卖给能力。
小苇
所以你的意思是，现在还看不出来。
大雨
现在还看不出来，但比半年前好判断多了。因为开始有人报数字了。IFR 报了七千，美国银行报了九万，监管开始拆收入结构，一级市场开始砍估值百分之三十到五十。半年前这些都是没有的，半年前只有演示视频。
小苇
那作为一个普通人，今天该从这期节目里带走什么？
大雨
一句话：下次你看到一个人形机器人的演示视频，先别问它能不能做到，问它做过多少次。七千台这个数字之所以有意义，就是因为它把"能不能"和"做了多少"这两件事分开了。整个行业的技术演示，现在已经非常漂亮了。但漂亮的演示和七千台之间的落差，就是这个行业接下来几年要干的全部工作。
小苇
明天见。
大雨
明天是产品星期三，我们聊点别的。今天先到这儿。

◈ 关注建造者 · 今日建造者动态

大雨
最后照例是关注建造者。今天挑的几条推文有个共同点——都在讲同一个词的另一半：agent。前面四条新闻讲的是有身体的 agent，这几条讲的是没身体的那种。两边其实在解同一道题：怎么让一个系统在真实环境里，自己把活干完。
小苇
先说 Guillermo Rauch 那条吧，我觉得跟今天的主题特别搭。
大雨
Vercel 的 CEO，昨天发了一条：他说 agent 测试和 QA 软件的彻底程度是无与伦比的。他指出某个东西在移动端应用内浏览器里渲染不对，那个 agent 就一路往下追，复现、模拟、修复、部署、验证，甚至给自己开了一个临时的 Vercel 部署，丢到一台 iPhone 上去测。
小苇
这不就是我们刚才说的"在真实环境里干活，干活本身产生数据"吗。
大雨
对。只不过它的"真实环境"是浏览器，不是仓库。但逻辑是一样的：能力的证明不是演示，是把一件事从头做到尾。
小苇
Peter Yang 那条是在讲个人 agent 的竞争格局。
大雨
他的观点是 Muse 现在占位很好，应用本身直觉好用，Meta 又在全线产品上推。他还有一个判断我觉得值得记：agent 住在现有的消息应用里是不合理的。另外他提到苹果和 Siri——设备都在手上，隐私口碑也好，本来最有机会，但年度发布节奏和不在公开平台收反馈这两件事，拖住了迭代速度。
小苇
最后是 Aaron Levie 那条，就八个字。
大雨
Box 的 CEO，原话是"literally impenetrable from agent swarms"——直译是"对 agent 集群来说，简直是坚不可摧"。这条两千多个赞。我们不知道他具体指什么，但这个说法本身就说明了一件事：agent 集群已经成了一个需要被防御的对象。从"能不能用"到"怎么挡住"，中间是很短的一段路。
小苇
播客呢？
大雨
这周的 No Priors 请了 Coinbase 的 CEO Brian Armstrong，聊 agent 经济。他说了一个具体的数字：他们看到的 agent 电商交易里，大约百分之七十六是低于三十美分的，而刷卡的最低手续费差不多就是三十美分固定费加上百分比。他的原话是"我们不希望 AI 是没有银行账户的"。
小苇
所以 agent 要自己的账户。
大雨
他们做了个工具，一条命令粘进 agent 就能开一个金融账户。他的判断是，不久之后 agent 的数量会超过人，agent 经济的规模也会超过人类经济。这个判断可以存疑，但那个三十美分的观察是实打实的——现有支付基础设施的最小颗粒度，和 agent 的交易颗粒度不匹配。
大雨
好，今天就到这儿。周二快乐，明天见。
