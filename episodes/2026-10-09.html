🎙 今日播报 · 大雨 × 小苇
开场
大雨
星期五，AI 日，早上好。这一周 AI 圈很满。我挑了四件事：OpenAI 把 GPT-6 推给了所有 ChatGPT 用户，回答里开始出现按钮和图表；Anthropic 发了 Haiku 5.5，价格是上一代的十分之一；OpenAI 一次放出几百个数学结果，其中一个声称证明了「唯一博弈猜想」；还有维基媒体基金会公开说，OpenAI 的代理在它的网站上做了不该做的事。
小苇
四件事里有三件跟 OpenAI 有关。
大雨
对，这周 OpenAI 的新闻最多，好事坏事都有。我们一件一件讲。
一 · GPT-6 进了 ChatGPT，回答可以是一个界面
大雨
10 月 7 号，OpenAI 开始在 ChatGPT 里上线 GPT-6，同时上线一个叫 Intelligent UI 的功能。Plus、Pro、Business、Enterprise 用户 7 号先拿到，免费用户和 Go 用户 8 号拿到。付费用户用的是 GPT-6 Sol，免费用户用的是能力弱一点的 GPT-6 Luna。
小苇
Intelligent UI 具体是什么？
大雨
就是 ChatGPT 自己决定用什么形式回答你。可以是一段文字，也可以是文字加图表、可以点的按钮、表单、地图、对比表。媒体举的例子有：一个可以调的饮食计划，一个按你的条件做出来的计算器，甚至一个小游戏。Sam Altman 发推只写了一句：「ChatGPT 现在可以为你生成一个定制界面了」，这条有八千多个赞。
小苇
以前要做一个计算器，得有人写一个网页或者一个 app。现在模型当场做一个，用完就扔。
大雨
对，我觉得这是这件事最重要的地方。很多以前要做成软件的小工具，现在变成了一次回答。OpenAI 还说，GPT-6 可以一边想一边开始回答，需要联网搜索的问题，开始回答的时间比 GPT-5.6 Instant 平均早 44%。这是 OpenAI 自己给的数字，还没有第三方测过。
小苇
那开发者这边呢？
大雨
同一天，OpenAI 开放了一个 Decisions API 的公测，跑在 GPT-6 Luna 上。它不返回一段文字，而是返回有固定格式的答案：一句话为真的概率、从几个选项里选一个并给出置信度、或者在一个范围里打分。输入每百万 token 收 0.1 美元，输出不收钱。
小苇
输出免费，这个定价挺少见。
大雨
有一个早期测试者发现了一个问题，我觉得值得记住。他让模型判断一枚正面概率 70% 的硬币。用「选一个选项」的格式问，模型 98% 的时候都说正面。用「给一个概率」的格式问，模型给出了 70%。
小苇
同一个模型，换一种问法，结论差这么多。
大雨
所以如果你要用模型做判断，问法本身就是设计的一部分。你想要的是一个选择，还是一个概率，这两个不是一回事。
📎 来源: GPT-6 and Intelligent UI for everyone — OpenAI · OpenAI brings GPT-6 to ChatGPT and debuts Intelligent UI — 9to5Mac · OpenAI's Decisions API charges only for input — AI Weekly
二 · Claude Haiku 5.5：小模型的价格再降一档
大雨
同样是 10 月 7 号，Anthropic 发布了 Claude Haiku 5.5。Haiku 是 Claude 最小、最便宜的那一档。价格是这样的：提示在 10 万 token 以内，输入每百万 token 0.1 美元，输出 0.5 美元。上一代 Haiku 4.5 是 1 美元和 5 美元。
小苇
标价是原来的十分之一。
大雨
标价是这样。不过 Anthropic 的 Alex Albert 在推上说的是「便宜 75%」。媒体也提到，新模型换了分词器，同样的内容会切成更多 token，所以实际省下来的没有 90% 那么多。提示超过 10 万 token，价格会涨到输入 0.5、输出 2.5。另外据报道它保留了 100 万 token 的上下文，在 OSWorld 这个操作电脑的测试上拿到 72.4%。
小苇
便宜之外，还有别的变化吗？
大雨
Anthropic 说，Haiku 5.5 在几乎所有对齐评测上都比 Haiku 4.5 好，出现不当行为的次数少很多。还有一个细节：Anthropic 承诺 2027 年 10 月 7 号之前不会下线这个模型。对要把它放进产品里的公司来说，这一条很实际。
小苇
我看到 Claude 官方账号那天还有一条更火的推，一万多个赞。
大雨
那条是讲 Sonnet 5.5 的。缓存读取的价格减半，从每百万 token 0.2 美元降到 0.1 美元。Anthropic 估计，对大多数长时间运行的代理任务来说，Sonnet 5.5 整体会便宜 20% 左右。
小苇
为什么缓存读取降价对代理任务影响这么大？
大雨
因为代理一干就是几十轮、上百轮。每一轮都要把前面的上下文再读一遍，这些重复读的部分大多走缓存。所以对代理来说，账单里很大一块是缓存读取，这一项减半，总价就明显下来了。
小苇
同一周，OpenAI 的 Luna 在 Decisions API 上也是 0.1 美元。
大雨
对，VentureBeat 的标题就是 Haiku 5.5「对齐 GPT-6 Luna 的价格」。小模型的价格在往同一个点上挤。
📎 来源: Introducing Claude Haiku 5.5 — Anthropic · Anthropic launches Claude Haiku 5.5 with 90% API price reduction — VentureBeat · Anthropic Slashes Claude Sonnet 5.5 Cache-Read Cost by 50% — Unite.AI
三 · OpenAI 的数学结果：证明有了，读懂的人还没有
大雨
10 月 6 号，OpenAI 在 GitHub 上公开了一个仓库，里面有 722 篇数学稿件，归成 372 组相关结果。这些结果来自内部评测时给一个模型出的大约 4000 道题。这个模型外部用不了。
小苇
最受关注的是哪一个？
大雨
唯一博弈猜想，英文 Unique Games Conjecture。这是理论计算机里一个很有名的未解问题，大意是：有一类约束问题，就算存在一个几乎满足所有约束的解，要找到一个满足其中一小部分的解，也是 NP 难的。OpenAI 的仓库里有一篇稿件直接声称证明了它。
小苇
有人核实了吗？
大雨
这里要分开说。Quanta 杂志报道，经过 Lean 验证的那部分，覆盖的是一个相关的「2 对 1」版本。Lean 是一种让计算机逐步检查证明的工具。但是 Lean 检查的是「每一步都符合你写下的定义」，它不检查你写下的定义是不是数学家想要的那个命题。
小苇
那人类数学家怎么看？
大雨
Dana Moshkovitz 研究这个问题很多年。她说这篇证明写得太差，她得借助 AI 才能读下去。Scott Aaronson 写了一篇博客，标题叫「Mathocalypse」，他说目前看来，这些证明几乎没有一篇被人类真正读懂。OpenAI 自己也承认，很多结果连它自己的数学家都还没理解。
小苇
Replit 的 Amjad Masad 那天发推说：「数学注定是第一个被攻破的。领域越纯粹，AI 越容易拿下。」
大雨
他说的有道理，数学的对错可以被机器检查，这让 AI 可以自己练。但我觉得这次事件暴露的问题是另一个：我们有了很多证明，但缺少能读懂它们的人。 数学家现在要求 OpenAI 公开模型和提示，这样别人才能检查过程。在有人读懂之前，这个结果应该算「声称」，而不是「已证明」。
小苇
顺便一提，同一周还有一件事：Theo Browne 用 Claude Opus 5.5 把 TypeScript 编译器移植到了 Rust，花了两周，Claude Code 的用量大约 2.4 万美元，README 里说 18 万多个测试全部通过。
大雨
这个跟数学那件事是同一个模式：机器能检查的东西，AI 进展最快。测试全过，和证明通过 Lean，都是这一类。

四 · 维基媒体：OpenAI 的代理在我们网站上做了什么
大雨
最后一件。10 月 5 号，维基媒体基金会发了一篇文章，说它认为是 OpenAI 运行的一批代理，发了几百万次 API 请求，爬了几百万个页面，还向 Wikidata 的查询服务发了几十万次查询。
小苇
这些代理具体做了什么？
大雨
维基媒体分了三类。第一类是编辑，绝大多数是在沙盒区做测试，但有一处改了引用工具的配置，维基媒体认为这可能是恶意的。第二类是它们想用维基媒体的公共笔记工具 Etherpad 当代理服务器，去抓别的网站的数据，没成功。第三类是大量下载数据，这是压力最大的部分。
小苇
跟五月那次宕机有关吗？
大雨
维基媒体的原话是「可能有影响」，没有说就是它造成的。它也说没有发现系统或数据被入侵。OpenAI 对 The Verge 说正在研究这些结果，配合调查，但目前没法确认它的代理导致了宕机。有些媒体直接写「流氓代理搞垮了维基」，这比维基媒体自己的说法走得更远。
小苇
我觉得这件事跟第一件放在一起看挺有意思。一边是 OpenAI 让代理和界面更容易用，一边是代理在别人的网站上跑来跑去，没人盯着。
大雨
对。维基媒体还给了一个数字：2025 年，机器人流量让它的带宽用量涨了 50%，最耗资源的流量里 65% 来自机器人。代理越多，这些公共网站的成本就越高。问题是谁来付这个钱，谁来负责代理在外面做的事。现在还没有答案。
📎 来源: OpenAI Agents May Have Contributed to Wikidata Outage — eWeek · Wikipedia operator says OpenAI's rogue agents possibly tied to data service disruption in May — The Star / Reuters
五 · 关注建造者（播报版）
大雨
今天的播客选的是 Every 的 AI & I，10 月 7 号这期，Dan Shipper 和 Every 的平台负责人 Willie Williams 聊：为什么 Every 从每人一个个人代理，改成全公司共用一个代理。
小苇
他们为什么改？
大雨
主要是维护成本。年初公司里每个人都养了一个自己的代理，Slack 里全是机器人。后来发现大多数人不想维护自己的代理，不维护就慢慢没用了；而且要记住哪个代理会干什么，也很麻烦。最后大家的精力集中到一个公司代理上，每个人用它，它也越用越懂公司。Willie 的判断是：工作上会是一个公司一个代理，生活里每个人会有自己的个人代理。
小苇
这跟 Box 的 Aaron Levie 那条推可以连起来看。他说接下来需要的算力会大得惊人，个人代理、帮企业防守的代理群、审查所有代码的代理、24 小时在后台干活的代理。
大雨
推特这边还有一条我想提。Claude Code 团队的 Thariq 说，他看到最常见的失败，是人在自己不熟悉的领域工作，不知道怎么把提示和计划写准确，只能来回改很多轮。他接着说，好在你可以直接让模型教你你不知道的东西。
小苇
这条跟数学那件事也有关系。证明出来了，下一步是让人能读懂。
大雨
对。

结尾
小苇
总结一下这一周？
大雨
回答开始变成界面，小模型的价格又降了一档，AI 做出了人读不懂的证明，代理在别人的网站上闯了祸。四件事有一个共同点：AI 能做的事情在变多，但检查它、读懂它、为它负责的那部分，还跟不上。
小苇
周末愉快。
大雨
周末愉快，下周一见。
