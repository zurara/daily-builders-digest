🎙 今日播报 · 大雨 × 小苇
开场
大雨
欢迎来到 Daily Builders Digest，今天是二〇二六年十月二十八号，星期三，产品日。我是大雨。
小苇
我是小苇。上周我们聊的是 AI 给一个人用还是几个人一起用。这周呢？
大雨
这周四条。第一条，OpenAI 发布 GPT-6.1 Terra，主打让模型直接操作电脑，价格比上一代便宜一半。第二条，Replit 连发几篇文章，提出「自动驾驶公司」，推出 Replit for Business 和 Cloud Agents。第三条，Akamai 推出 Agent Sandbox，给 agent 一个隔离的运行环境；同一天 Vercel 的 CEO 演示了隔离环境怎么被绕过。第四条，苹果这一周每天发一款新品，今天是正式的「Pro and tell」，预计会发带触屏的 MacBook Pro。
小苇
前三条都跟 agent 有关，苹果放进来是为什么？
大雨
前三条讲的是 agent 接手电脑上的活。苹果这条讲的是人自己用电脑的方式还在变。两件事放在一起，我想问的是：agent 能点鼠标、能改代码、能自己上线以后，人在产品里负责哪几步？
一 · GPT-6.1 Terra：会用电脑的中档模型
大雨
先说事实。十月二十六号，OpenAI 把中档模型 Terra 从 GPT-5.6 升到 GPT-6.1。OpenAI 现在有四档模型，从便宜到贵是 Luna、Terra、Sol、Astra。上个月 Sol 和 Luna 升到了 GPT-6，Terra 这次才跟上。
📎 来源: OpenAI upgrades ChatGPT and Codex with new GPT-6.1 Terra model — 9to5Mac
小苇
这次主要改了什么？
大雨
OpenAI 的说法是，这个模型擅长「填满工作日的那些电脑上的活」：写提案、看技术图纸、填表、剪视频。报道里举的例子是处理收到的发票，把信息录进会计软件。价格是每百万输入 token 一美元，输出五美元，比 GPT-5.6 Terra 便宜一半。ChatGPT Work、Codex 和 API 当天都能用。
小苇
便宜一半，能力还更好？
大雨
按 OpenAI 自己的测试是这样。他们有一组专门诱导出错的提示词，低推理强度下，错误率从 53.6% 降到 16.7%；最高推理强度下降到 4.3%，接近 Astra 和 Sol。Terminal-Bench 4.0 上，最高强度是 50.3%，上一代是 21.5%。这些都是内部评测，还没有第三方复现。
📎 来源: OpenAI launches GPT-6.1 Terra with 3x faster AI agents, 50% lower pricing — BleepingComputer
小苇
建造者那边反应怎么样？
大雨
今天点赞最多的两条推文都是这个。负责 Codex 的 Thibault Sottiaux 说，Terra 是他们第一个在写作、个性和理解细微要求上明显更好的模型，电脑操作很强，用量是 6.1 Sol 的两倍。Sam Altman 说他们最兴奋的是「电脑操作的新时代」。Greg Brockman 说，电脑操作过了一个门槛，感觉它用电脑比他自己还快。
小苇
我想问一个做产品的问题。如果模型能直接点你的界面，那界面还是给人设计的吗？
大雨
这正是我想说的。以前做企业软件，有两套入口：给人用的界面，给程序用的 API。很多老软件没有 API，或者 API 只开放一半。现在 agent 可以直接看屏幕、点按钮、填表，这些软件不用改，也能被自动化了。
小苇
那对做软件的人是好事还是坏事？
大雨
两面都有。好的一面，你的产品不用先做完整 API，也能进到客户的自动化流程里。坏的一面，客户可以让 agent 绕开你精心设计的流程，你看到的「用户」可能不是人。我觉得做产品的人现在要多看一类数据：你的界面上，有多少操作是 agent 做的？它们卡在哪一步？
二 · Replit：「自动驾驶公司」
大雨
第二条。十月二十六号，Replit 发了一篇文章，标题是「自动驾驶公司的兴起」，同时推出 Replit for Business。CEO Amjad Masad 在推特上说：几百年来，公司的结构基本没变，都是人按部门分层，靠流程协调。AI agent 会把这个打破。他们说的方向是：人做判断，agent 做大部分执行。
📎 来源: The Rise of the Self-Driving Company — Replit Blog
小苇
「自动驾驶公司」，这个说法有点大。具体产品是什么？
大雨
看他们这一周发的三样东西。十月二十二号是 Monitoring Agent：它能发现线上问题、查原因、验证修复，然后自动发布。自动发布是可选的，默认是你自己审完再发。十月二十六号是 Replit for Business，按报道是帮企业管理 agent 部署。十月二十七号是 Cloud Agents，文章标题是「任何人都能把想法带进公司代码库」，副标题是：Cloud Agents 构建和测试改动，由工程师决定哪些上线。
📎 来源: Anyone can now bring their ideas into the company codebase — Replit Blog
小苇
我注意到三样东西里都有一个「人来批准」的开关。
大雨
对。名字叫自动驾驶，但每个产品都留了一个人来决定的位置：Monitoring Agent 的自动发布要你打开，Cloud Agents 由工程师决定上线。我觉得这是诚实的设计。现在 agent 能做的事，和公司敢让它直接做的事，中间还差一段。
小苇
这跟今天的播客也能接上。
大雨
对，后面关注建造者那里细说。先说一句：自己做的工具要自己维护，Monitoring Agent 卖的其实就是维护。
三 · Akamai Agent Sandbox，和 Guillermo Rauch 的 cpu-chat
大雨
第三条，两件事一起说。十月二十七号，Akamai 推出两款云 AI 产品，其中一个叫 Agent Sandbox，给 AI agent 一个运行环境。代码在隔离环境里执行，用 WebAssembly 限制计算、内存、对外连接和系统权限。这个组件在 Spin 框架里开源。目前是 beta。
📎 来源: Akamai launches AI inference and agent sandbox products — Investing.com
小苇
做 CDN 的公司也开始做 agent 沙盒了。
大雨
这说明「给 agent 一个关起来的地方跑」已经变成一个基础产品，跟数据库、存储一样。前一天，Vercel 的 CEO Guillermo Rauch 发了一条两千赞的推文。他做了一个叫 cpu-chat 的东西，复现了 OpenAI 之前公开的一个发现：两台互相隔离、都不能上网的 Firecracker 微型虚拟机，可以通过 CPU 传消息。
小苇
不联网怎么传？
大雨
他用了三种办法：抢 CPU、缓存被挤掉的时间差、内存带宽的争用。一边故意让某个资源变忙，另一边测量自己变慢了多少，慢和不慢就是一和零。他说在 x86 和他自己的 M5 Mac 上都能跑，而且按 Firecracker 官方的生产环境建议配置，也挡不住。
小苇
那沙盒还有用吗？
大雨
有用。这种传法很慢，要两个程序事先约好。沙盒挡住的是大部分问题：agent 乱删文件、乱发请求、偷偷联网。但它提醒做产品的人一件事：「隔离」不是一个开关，它是一组限制，每一条都有边界。你跟客户说「agent 在沙盒里很安全」的时候，最好能说清楚安全到哪一步。
四 · 苹果「Pro and tell」：一周每天发一款
大雨
第四条。苹果这次没有开传统发布会。十月二十六号周一先发了新 iPad mini：OLED 屏幕、A20 Pro 芯片、更薄、防水防尘，起价 699 美元。苹果市场营销高级副总裁 Greg Joswiak 在推特上说，这只是「激动人心的一周」的开始。二十七号周二发了 M6 芯片的 iMac 和 14 英寸 MacBook Pro。
📎 来源: Apple teases an 'exciting week' of new products ahead — 9to5Mac
小苇
今天是正日子？
大雨
对，今天太平洋时间上午十点，在洛杉矶。按彭博 Mark Gurman 的说法，会发 14 和 16 英寸的 MacBook Pro，OLED 屏幕，支持触控。我们录节目的时候还没开始，所以这一点先当作预期，不当作事实。
📎 来源: Pro and Tell event live blog — Macworld
小苇
苹果以前一直说 Mac 不需要触屏。
大雨
是。如果今天真的发了，这是一个很大的转向。我更关心的是发布方式。把一场发布会拆成一周、每天一条新闻，每款产品都能单独占一天头条。今年早些时候 MacBook Neo 也是这么发的。
小苇
这跟前面三条的关系呢？
大雨
前面三条，OpenAI、Replit、Akamai 都在做一件事：让 agent 替人用电脑。苹果这周做的是另一件事：让人用电脑的方式更多，手指可以直接点屏幕了。两件事同时发生。我觉得接下来两年，做产品的人要同时为两种使用者设计：一种是拿手指点屏幕的人，一种是看截图点坐标的 agent。
关注建造者
小苇
最后是关注建造者。
大雨
今天挑了四条。第一条是 Thibault Sottiaux，前面说过，八千七百赞，讲 Terra 的写作和电脑操作。第二条是 Claude 官方账号，五千四百多赞：现在有两万五千多家非营利组织在用 Claude，大多是小型本地团队。他们和大约三十家机构一起做了一个插件，加了筹款、营销、招聘的技能，按每个团队自己的情况和 AI 使用规定来用。
小苇
这条跟「自动驾驶公司」正好是两个极端。一边是要把整个公司交给 agent，一边是几个人的小团队，先把筹款邮件写好。
大雨
对。而且小团队的需求很具体：要符合自己机构的 AI 使用规定。第三条是 Guillermo Rauch 的 cpu-chat，两千赞，刚才讲过。第四条是 Amjad Masad，一千一百多赞，只有一句话：软件吃掉了世界，现在它在学着运营世界。
小苇
还有一条 Peter Yang 的我挺喜欢。
大雨
嗯，赞不多，四十九个。他说，以后人们在网上不会自己读、自己做什么，而是直接 @ 自己的 agent 去做。然后他自己又在下面回了一句：这总体上可能不是好事。
小苇
他自己都犹豫。
大雨
播客推荐是 Every 的 AI & I，十月十四号那一期，主持人是 Every 的 AI 咨询负责人 Natalia Quintero，嘉宾是 Factorial Capital 的 Matt Hartman。他在 Betaworks 的时候参与投了早期的 Hugging Face。这一期比我们通常的范围早两周，是 feed 里唯一的一期，但有一段跟 Replit 正好能对上。
📎 来源: AI & I by Every · How Hugging Face's Investor Spots Winners
小苇
哪一段？
大雨
Matt 自己用 Claude Code 做了一个本地语音转文字的小工具，叫 Ghost Pepper，GitHub 上有三千多星。他说做完以后学到一件事：自己做的东西，得自己维护。大家都在说 SaaS 要完了，可这些付费软件其实不贵，你付的钱买的是有人一直更新、一直保持它好用。Natalia 也说，她自己做过一个 CRM 工具，用了几个月，发现花在维护上的时间太多，最后把数据迁到了现成的产品上。
小苇
所以 Replit 的 Monitoring Agent 卖的是这个：你自己做的软件，维护的活交给 agent。
大雨
对。能不能卖出去，就看大家敢不敢打开那个自动发布的开关。
结尾
小苇
今天的问题留给大家：在你做的产品里，如果明天有一半操作是 agent 做的，你会先改哪个界面？
大雨
我们下周三见。今天是十月二十八号，这里是每日快报。
