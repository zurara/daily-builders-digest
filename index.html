◈ 今日焦点 · 造物门槛正在塌向每个人 · 精选四条

01 · 头条

Roblox Build 公开内测：一个九岁的孩子，一句话，在手机上做出能玩的游戏

七月二十八号，Roblox 的新功能 Build 开始公开内测，第一站是新西兰。它是一个手机优先的 AI 工具——你用大白话描述一个游戏，比如「在末日城市里开赛车、能捡道具」，Build 就直接生成一个能玩的初版，带上玩法机制、场景、角色、视觉风格和音效。生成完可以当场试玩、用聊天让它改、分享给朋友，或接着搬进桌面版 Roblox Studio 继续做，两边共用同一套后端、模型和聊天记录。内测门槛是新西兰、九岁以上、完成年龄验证，十六岁以上才能把作品发布给全球玩家。方向值得注意：过去「说一句话就出东西」主要发生在程序员、设计师手里，Roblox 把它直接递到了一个用手机的孩子面前。造物的门槛不是降了一点，是塌到了地板上。

📎 Roblox Newsroom  ·  TechCrunch

02

ChatGPT Work + Codex 冲上八百万用户：专业工作流被压缩成一句吩咐

OpenAI 把聊天、Codex 编程和「帮你把活干完」的 ChatGPT Work 揉进一个桌面 App，七月九号上线，到十四号活跃用户就冲到八百万——二月还只有一百万，两天前才六百万，涨得像坐火箭。这周负责人 Thibault Sottiaux 一边庆祝「重置了所有付费用户的用量上限」，一边说「感觉自己也被 reset 了一下」。更能说明问题的是它已经溢出程序员圈：OpenAI 的 jxnlco 在骑车途中被同事要求改一条发布视频，他从手机远程让 Codex 剪好、导出、发回 Slack，还交代「每三十分钟看反馈、导出 V2/V3/V4」；等他骑车到家，视频已被批准。他甚至没在「做」，只是说了一句，然后走开。

📎 explainx.ai

03

Schlage Sense Pro：连「说」都省了——你走过来，锁就先懂了

「说出来它就成了」不只发生在屏幕里。这周 Schlage 推出新智能锁 Sense Pro，带触摸屏、支持 Matter 智能家居标准、支持苹果 Home Key，但真正有意思的是那颗超宽带（UWB）传感器——它能算出你走近门的速度和方向，在你还没伸手去够门把手之前，就先把锁开了。把它和前两条连起来：Roblox 是「你说，它造」，ChatGPT Work 是「你说，它办」，Schlage 是连「说」都省了，「你走过来，它就懂了」。三个点在同一条曲线上，方向一致——把「意图」和「结果」之间的摩擦一点一点磨掉。

📎 CNN Underscored

04 · 观察

当造东西几乎免费，稀缺的东西换了位置——从「能不能造」变成「造得好不好」

门槛塌下来是好事，但它会把稀缺换个地方。当谁都能一句话生成一个游戏、一份文档、一段视频，产出本身就不值钱了，满世界都是「能用」的东西。这时真正稀缺的是判断力：哪个想法值得做、这一版到底好不好、该砍掉什么。Linear 产品负责人 Nan Yu 这周说得很损也很准：「一大批很聪明的人努力把产品做得很好、很好用；如果你手上有很聪明的人，就该让他们把你自己的产品做好——然后付我们一点小钱用我们的产品就行。」生成能力可以外包、可以买，但「把产品做好」的那份判断和品味外包不掉。Meta 的 Madhu Guru 补了一刀：最好的产品评审会是在一小时里模拟出市场对你想法的真实反应，而这只有屋里的人真懂领域、有强观点、还经常判断对才成立。今天给产品人的问题因此有两层——大处：门槛塌了，你打算把它递给谁、解放谁？小处：满世界都是「能用」的东西，你凭什么让人记住你这一个？答案八成不在「造得更快」，而在「判断得更准」。

📎 Nan Yu · X  ·  Madhu Guru · X
