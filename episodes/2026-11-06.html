🎙 今日播报 · 大雨 × 小苇
开场
大雨
星期五，AI 日，早上好。这周美国中期选举，AI 公司的新闻也挤在这几天。
小苇
今天讲几条？
大雨
三条主要的。第一，OpenAI 发布了专门做安全研究的模型 GPT-6 Cyber，同时公布了一次在 Linux 内核里找漏洞的实验。第二，OpenAI 要收购 Pierre，一家给编程代理做 Git 存储的公司。第三，选举日有 41 个地方投票跟数据中心有关，两天后 OpenAI 发了一份建数据中心的承诺。最后是几条短消息和建造者动态。
一 · GPT-6 Cyber：948 个能用的提权漏洞
大雨
11 月 5 号，OpenAI 发布 GPT-6 Cyber。这是一个专门训练来找软件漏洞、写利用代码、再给出补丁的模型。
小苇
找到了什么？
大雨
OpenAI 给了两个实际案例。一个是 Firefox：模型找到 81 个以前不知道的漏洞，Mozilla 评为高危，已经开始发修复。另一个是 Linux 内核。OpenAI 前一天发了一篇研究文章，标题叫「A thousand fewer paths to root」，意思是少了一千条拿到 root 权限的路。
小苇
内核那个怎么做的？
大雨
一套自动化的代理流程。先扫了大约 5000 个跟安全有关的代码位置，筛出 2308 个候选，在隔离的虚拟机里复现了 1724 个，最后写出了 948 个能用的本地提权利用。同样条件下，上一代 GPT-5.6 Sol 只写出 166 个。304 个严重问题已经连同补丁建议报给了内核维护者。
小苇
花了多少钱？
大雨
整个流程大约 121 万美元的算力，平均每个利用 1279 美元。The Decoder 做了个对比：Pwn2Own 这类比赛，类似的发现过去奖金是 2 万到 7 万美元一个。
小苇
这么强的东西，谁能用？
大雨
现在只给一小部分 Daybreak Red 客户，通过 API 和 Codex 使用，默认开 IP 白名单。OpenAI 在自己的风险框架里把它评为 Critical，也就是网络安全这一项的最高级。它还测了一件事：在任务周围故意放一些越权的诱饵目标，看模型会不会越界。不加安全提示时，99.93% 的情况下没越界，上一代是 94.49%。
小苇
这些数字有人独立验证吗？
大雨
没有。基准分数都是 OpenAI 自己报的。能从外部核对的是 Mozilla 那边的安全公告和已经发出的修复。
小苇
我关心的是：这类模型如果流出去，或者开源模型追上来，怎么办？
大雨
The Decoder 同一篇文章里提到，Epoch AI 刚发现开放权重的 GLM 模型已经能利用 Firefox 里已知但还没修的漏洞。所以 OpenAI 说的是一个「窗口期」：趁最强的模型还在防守方手里，先把常用软件修一遍。这个窗口有多长，没人说得准。

二 · OpenAI 收购 Pierre：代理写的代码放在哪
大雨
第二条。11 月 4 号，OpenAI 宣布要收购 Pierre Computer Company。这家公司做 Code Storage，一个给机器用的 Git 托管服务，可以通过 API 批量建仓库。它还有三个开源工具：Trees、Diffs、Highlights，分别用来显示文件树、显示代码改动、做语法高亮。
小苇
跟 Codex 什么关系？
大雨
OpenAI 说 Pierre 的工具已经在 Codex 里用着了。收购完成后，Code Storage 的功能会并进 Codex。老客户可以继续用，开源项目继续开源。价格没公布，还要等监管批准。
小苇
为什么要买一个 Git 服务？
大雨
OpenAI 的原话是：在开发者已经在用的 Git 流程上，改造成适合团队和编程代理一起工作的样子。实际问题是，人一小时提交几次，代理几分钟就能开几十个分支。审代码的人面对四十个小提交，比面对三个大提交难得多。Axios 的标题直接说这是冲着微软的 GitHub 去的。OpenAI 自己没提 GitHub。
小苇
那对用 Codex 的人来说，变化是什么？
大雨
现在没变化。以后可能是模型、代理、代码仓库都在一家公司。好处是一条龙，坏处是你的提交历史也放在了同一家。Tech Insider 的建议很实际：主仓库放在你自己能控制的地方，把 Codex 当客户端用。
小苇
这周还有一条也是关于编程代理的？
大雨
对，有报道说 Meta 收购了做多代理并行编程的 Conductor，但我们没找到 Meta 或 TechCrunch 的原文，今天先不展开。

三 · 数据中心上了选票，OpenAI 发了一份承诺
大雨
第三条。11 月 3 号选举日，Ballotpedia 统计有 41 个地方投票事项跟数据中心有关，分布在 10 个州，其中俄亥俄州就有 21 个。
小苇
结果呢？
大雨
方向很清楚，大多数结果是限制数据中心。但具体数字各家说法不一样：有的说 41 个里有 40 个否决了新数据中心，有的说其中只有 3 个是暂停开发。还有社交媒体上流传的「43 比 1」，没有可靠出处。所以我们只说方向，不说精确比分。
小苇
OpenAI 的承诺是什么？
大雨
11 月 5 号，OpenAI 发了两份文件。一份叫 National Community Compact，是它对自己的约束：自己拥有和运营的数据中心，电费自己付；优先用闭环冷却省水；向居民公开施工计划、噪音、用水和能耗；招聘本地人，跟工会合作培训；还有一条，以后谈选址时不再跟地方官员签保密协议。另一份是给立法者的政策建议，希望把这些要求变成全行业的规定。
小苇
不签保密协议，这条挺具体的。
大雨
是。过去很多数据中心项目，镇议会签了保密协议，居民到最后才知道建的是什么、给谁建。这次很多投票就是冲着这个来的。
小苇
有什么漏洞？
大雨
Tech Insider 列了几条。一，这是自愿的，做不到也没有处罚。二，只管「以后」的、「OpenAI 自己拥有和运营」的园区。合作方建的、OpenAI 只是租用的，不在里面。三，「专有信息」可以保密，这个例外可大可小。
小苇
选举后两天就发，看起来像补救。
大雨
时间上确实是。能不能让人信，要看第一批地方协议里有没有具体数字、谁来核查。

四 · 几条短消息
大雨
第一条，11 月 4 号 OpenAI 发了 ChatGPT Images 2.6，可以生成 GIF 动图，可以保存参考图。API 里多了两个更快的图像模型，还能导出 SVG。
大雨
第二条，据报道，Anthropic 从 11 月 3 号开始给 Claude 生成的文字加不可见水印，11 月 16 号扩展到更老的几个模型。有个细节：老模型只有在 temperature、top_p、top_k 都保持默认时才加水印。背景是欧盟 AI 法案第 50 条，透明度要求的过渡期 12 月初结束。
大雨
第三条是人事。之前在 Anthropic 做 Claude Code 的 Cat Wu 宣布加入 OpenAI，负责核心产品的产品管理。这条在下面建造者部分再说。

五 · 关注建造者
大雨
今天的播客是 Every 的 AI & I，11 月 4 号这一期，嘉宾是 Kevin Roose。他以前是《纽约时报》的科技记者，刚出了一本书，写过去十年造出现代 AI 的那批人。
小苇
他怎么让这些人开口的？
大雨
他说总共采访了大约 150 人。最难的是前 25 个。大部分采访是匿名的，不写出处。后来就滚雪球了：圈子很小，大家互相问「你跟 Kevin 聊了吗」。还有人是因为讨厌的人已经跟他聊了，想把自己那一面也讲清楚。
小苇
他觉得我们完了吗？
大雨
他说没完，但要做的事很多。他提了两步：第一步，像药品上市前必须测试一样，模型发布前要做标准的安全测试，比如会不会自主发动网络攻击。第二步，前沿实验室之间要有一个放慢速度的协调机制。他说这几个月他改变了看法，以前觉得慢不下来。
小苇
跟今天第一条正好对上。
大雨
对。他还推荐了一份材料：Dario Amodei 2017 年在 OpenAI 写的内部备忘录，叫「big blob of compute」假说，意思是别做窄模型，把大量算力对准通用问题，比如预测下一个词。他把前 10 页发在了自己的 Substack 上。
小苇
推文呢？
大雨
点赞最多的是 Cat Wu，一万一千多。她说自己加入 OpenAI 领导核心产品的产品管理，理由是 OpenAI 证明了 scaling 有效，把 AI 带给了十亿人。
小苇
她之前在 Anthropic 做 Claude Code。
大雨
是。第二条是 Vercel 的 CEO Guillermo Rauch。他说接下来我们会发现，大部分人写的软件很慢、漏洞很多、需求没写清楚。AI 会把它们重写很多遍，还会做形式化验证和压力测试。他另一条推文给了数字：Vercel 的安全审查上线 24 小时，找到 6817 个漏洞，580 个高危或严重，1411 个已经由代理修好。
小苇
跟 GPT-6 Cyber 是同一件事。
大雨
对。第三条是 Peter Steinberger，他问：个人额度还有意义吗？他的意思是，以后你支持的是一个代表项目的代理，它跑循环、改代码，人只负责挑选自动化流程。
小苇
这跟 Pierre 那条也连上了。
大雨
最后一条是 Ryo Lu，做过 Cursor 和 Notion 的设计。他在上海的 AI Engineer 大会上讲了一个问题：当我们什么都能做出来的时候，我们还知道自己想要什么吗？他说他想要的工具，是帮人自己找到答案，不是跳过形成答案的过程。
结尾
小苇
今天几条放一起看呢？
大雨
模型已经能大规模找漏洞，OpenAI 想把代码仓库也收进来，数据中心建不建要地方居民投票。AI 公司现在要同时管好模型、代码和机房。
小苇
这周末可以做一件事：看一下自己项目用的依赖，有没有最近发的安全更新。
大雨
好，这期就到这里。我是大雨。
小苇
我是小苇。周末见。
