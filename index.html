🎙 今日播报 · 大雨 × 小苇
开场
大雨
星期一，AI 日，早上好。上周五我们讲了 GPT-6 Cyber，今天安全这条线还在继续。
小苇
今天讲几条？
大雨
三条主要的。第一，安全：微软发现攻击者用 AI 代理从 GitHub 一路摸进云端，DeepMind 用代理在 RSA-1024 里找到两个弱点，OpenAI 请外部团队用代理攻击自己。第二，钱：OpenAI 新一轮融资先拿到 110 亿美元，估值比原来想要的低；Anthropic 上市的时间也不确定了。第三，OpenAI 发了一个测试代理能不能看懂湿实验数据的基准。最后是几条短消息和建造者动态。
一 · 安全：代理去攻，代理去守
大雨
先说攻击这边。11 月 5 号，微软威胁情报团队发了一篇报告。攻击者用一个叫 ARTEX 的代理框架，自动在公开的 GitHub 仓库里找泄露的密钥和 API key。
小苇
找密钥的脚本早就有了，这次有什么不同？
大雨
不同在于找到之后不停。代理会判断这个密钥能干什么，接着去登录云服务、翻 Key Vault 和存储账户、下载 SharePoint 和 OneDrive 里的文件，再去找更多凭据。微软记录到一个案例，从在 GitHub 上搜到密钥，到从 Azure Key Vault 里拿走数据，大约五分钟。
小苇
五分钟，人基本来不及反应。
大雨
对。所以微软的建议很直接：只要密钥在公开仓库里出现过，就当它已经泄露了。删掉那次提交没用，密钥本身还有效，必须轮换。另外要查 Entra ID 登录日志、Azure 活动日志和 Key Vault 访问记录，能用托管身份的地方就别用长期密钥。
小苇
防守这边呢？
大雨
11 月 6 号，Google DeepMind 公布了一项研究：研究人员带着 AI 代理，在 1024 位 RSA 上找到两个弱点。一个跟签名有关，一个是批量分解，就是一次分解很多个 1024 位的密钥时，每多一个的平均成本降了大约 30 倍。还有一个小实验：两个代理用不到四天，自己设计、运行、调试了一次计算，复现了一个已知结果，用的 CPU 时间是原来的三分之一左右。
小苇
这是说 RSA 被破了？
大雨
不是。1024 位早就被认为不够安全了，现在主流是 2048 位以上，这项研究没说 2048 位有问题。签名那个弱点有一个 1600 倍的数字，原文也说是理论估计。我们看到的都是二手报道，没读到 DeepMind 的原文。值得记住的是 Pushmeet Kohli 的说法：这类进展过去要几年，这次代理用了几周。
小苇
那 OpenAI 那条呢？
大雨
同一天，OpenAI 宣布和一家叫 Hacktron 的安全公司合作。Hacktron 做代码审查和渗透测试的代理，OpenAI 给它开放前沿模型，让它重点测 OpenAI 自己的系统跟第三方服务连接的地方。
小苇
三件事放在一起，攻和守用的是同一类工具。
大雨
是。区别只在谁先用。对普通开发者，今天能做的事就是微软那条：查一下自己的公开仓库，有没有提交过密钥。

二 · 钱：OpenAI 估值降了一档，Anthropic 上市时间不确定
大雨
第二条。11 月 6 号，路透转述彭博的消息：OpenAI 新一轮融资先拿到了 110 亿美元，估值 1.25 万亿美元。投资方有软银和 MGX。
小苇
1.25 万亿，听起来还是很多。
大雨
数字本身是。但有几家报道说，这一轮原本想按 1.4 万亿左右估值，总额原本想融 300 亿，现在降到 200 亿左右。作为对比，今年 3 月底 OpenAI 上一轮是 1220 亿美元，投后估值 8520 亿。
小苇
为什么降？
大雨
报道给的理由是投资人对 AI 基础设施的投入更谨慎了。机房、芯片、电都要钱，投入回报的时间越来越长。上周五我们讲过，美国好几个地方投票限制建数据中心，也是同一个背景。
小苇
Anthropic 呢？
大雨
Anthropic 在准备上市。路透之前报道，路演原计划就是这周，11 月 9 号这一周开始，下一周定价。但路透后来又报道，有投资人怀疑 Anthropic 能不能按这个时间走完。估值方面，各家说法不一样，之前流传的是 2 万亿左右，也有更低的说法。Anthropic 自己没确认日期。
小苇
收入呢？
大雨
有报道说上个季度收入接近 170 亿美元，但增速放慢了，算力成本也多了一大块。这些是从报道里来的，没有官方文件可以核对。
小苇
两家公司放一起，看出什么？
大雨
私募市场和公开市场开始给同一个问题打分：前沿模型公司到底值多少钱。Anthropic 一旦上市，每天都有一个公开价格。建造者 Aditya Agarwal 发了一条推文，说如果新建数据中心越来越难，手上已经有算力的大云厂商会占便宜，受影响的是新模型训练的速度。

三 · BioBasicsBench：代理能看懂实验室的原始数据吗
大雨
第三条。11 月 6 号前后，OpenAI 发布了一个基准，叫 BioBasicsBench，跟酶设计公司 Ligo 一起做的。100 个任务，测的是 AI 代理能不能看懂湿实验的原始数据。
小苇
原始数据指什么？
大雨
电泳胶图、细胞培养的照片、显微镜图像、仪器读数，还有失败的实验、看不清的图、互相矛盾的结果。OpenAI 的理由是：论文里挑出来的图都是干净的，真实实验室每天面对的是不干净的东西。评分也不只看答案对不对，还看模型能不能发现错误，能不能说出「证据不够，下不了结论」。
小苇
成绩怎么样？
大雨
GPT-6 Astra 在最高推理设置下拿到 66.7% 的分。上一代 GPT-5.6 Sol 是 43.8%。
小苇
66.7% 算高吗？
大雨
不好判断，因为 OpenAI 没给人类基线，也没测别家的模型。OpenAI 自己写了一个失败案例：数菌落，模型分不开挨得很近的菌落，漏数了看得见的，还在空的琼脂上标了菌落，最后多数了大约 12%。OpenAI 也说，分数高不代表模型已经能在实验室里可靠判断。
小苇
这个基准不管动手的部分？
大雨
对，移液、操作仪器、机器人执行都不在里面。只管看数据、下判断这一步。

四 · 几条短消息
大雨
第一条，Thinking Machines，就是 Mira Murati 的公司，11 月 5 号发布了 Inkling 2 Small。混合专家模型，总参数 5940 亿，每个 token 激活 170 亿，能看图，主要面向编程代理和长时间自主任务。现在在他们的 Tinker 平台上用。权重是不是已经公开，各家报道不一致，有的说要等外部安全测试之后再按 Apache 2.0 发布。
小苇
名字叫 Small，五千多亿参数。
大雨
对，Small 是相对 7 月那个 9750 亿参数的版本说的。第二条，英伟达在推它的 Vera CPU，说这是给代理工作负载设计的。代理不是一直在 GPU 上跑，它要执行代码、查数据库、调工具，这些活在 CPU 上。英伟达说在 100 兆瓦的数据中心里，Vera 每瓦能支撑的代理比测试的 x86 处理器多，Perplexity 在编程代理任务上快了大约 1.5 倍。这些是英伟达自己的数字。
小苇
跟 Aaron Levie 那条推文能对上。
大雨
等会儿说。

五 · 关注建造者
大雨
今天的播客是 No Priors，11 月 5 号这一期，嘉宾是 Robinhood 的 CEO Vlad Tenev。
小苇
跟 AI 有什么关系？
大雨
关系挺大。Robinhood 今年早些时候上线了一个 MCP，他们叫 Agentic Trading，就是让代理帮你执行交易策略。他说几个月里有超过 15 万个客户开了代理交易账户，工具调用每天大约 3000 万次。几周前他们又发布了 Robinhood Agents，把整个代理的运行环境搬进 Robinhood 账户，他自己的比喻是：像 Claude Code 或 Codex，但专门为交易做的。可以每天定时跑你的策略、调仓，还有一个应用商店，比如接卫星数据去数零售商停车场里的车。
小苇
这不就是把对冲基金的工具给散户吗？
大雨
他就是这么说的，目标是把对冲基金和量化公司的能力放进普通人口袋。他也承认，一开始受益的是一小部分本来就懂的人，他们的交易量会大涨，然后才慢慢扩散。跟编程代理一样，先用上的是本来就会写代码的人。
小苇
还聊了别的吗？
大雨
聊了预测市场。他说预测市场是新闻的下一种形态，很多人打开 App 不交易，只是看赔率，了解接下来可能发生什么。还聊了他做的数学 AI 公司 Harmonic。他觉得现在 AI 做数学太集中了，都是大公司用自己的机房和不公开的模型在做。
小苇
推文呢？
大雨
点赞最多的是 Karpathy，六千四百多。有人发了自己最喜欢的 YouTube 频道列表，他用 Claude Code 三分钟做成了一个网站，叫 TristanTube，4.7 万个视频，还有一个躺着看的电视模式。
小苇
三分钟，一次做成。
大雨
对。第二条是 OpenAI Codex 的 Thibault Sottiaux。他澄清 Pro 套餐都没有 5 小时限额，Pro 100 是 Plus 的 10 倍用量，Pro 200 是 20 倍，Pro 500 是 50 倍，还能用 ultrafast。
小苇
第三条是 Levie？
大雨
是 Box 的 CEO Aaron Levie，两条。一条说，他开始看到有人用 AI 后的产出比以前高一到两个数量级，条件是：好的运行环境、对自己领域很熟、代码库比较新、会同时带多个代理、测试和部署没什么阻力。他说这个差距没有缩小，反而在拉大，原来功底越深，现在杠杆越大。
小苇
另一条呢？
大雨
另一条就是刚才说的。他说代理对延迟不敏感，一个任务值 500 美元，晚一秒返回没关系。所以推理不用放在用户旁边，数据中心可以建在任何愿意建的地方。愿意建的州和国家有机会，不愿意的就错过。
小苇
跟前面数据中心那些投票正好相反的意见。
大雨
对，两边都摆在这里了。
结尾
小苇
今天几条放一起看呢？
大雨
代理已经被拿来攻击，也被拿来做安全研究和看实验数据。同时，造这些代理的公司，融资和上市都比几个月前难了一点。
小苇
今天可以做一件事：去 GitHub 搜一下自己的公开仓库，看看有没有提交过 .env 文件或者 API key。有的话，马上轮换。
大雨
好，这期就到这里。我是大雨。
小苇
我是小苇。明天机器人日见。
