◈ dots 的权限规则（据 OpenAI）
后台只读，动手要过规则
01后台「主动研究」。你不找它时，dot 只能以只读方式使用连接的应用，不能发消息、不能改内容。
02自定义规则。对具体动作可设为允许、禁止或需要批准。
03自动审核。可能影响账户或对外分享信息的动作会先被检查；监控系统可暂停或停止 dot。

◈ 一 · OpenAI 发布 dots：一直开着的 agent

大雨
九月二十九号周二，OpenAI 在旧金山开 DevDay，宣布了二十多样东西。Sam Altman 后来在一个访谈里说，前几年 DevDay 只有四五样，去年九样左右。今年最受关注的是 dots。
小苇
dots 是什么？
大雨
是一种 agent。每个 dot 有自己的云端电脑和浏览器，跑在 GPT-6 Astra 上，能通过插件连接四千多个应用。你可以在 ChatGPT 的桌面版、网页版、手机上给它发消息、打电话，也可以在 Slack 和 Teams 里给它发消息。
小苇
和以前的 agent 有什么不同？
大雨
主要是它一直在跑。你不找它的时候，它会在后台找能帮你的事，OpenAI 叫这个「主动研究」。但这时候它对连接的应用只有只读权限，不能发消息，也不能改内容。
小苇
那它什么时候能动手？
大雨
有内置规则，规定哪些事可以自己做、哪些要先问你。你也可以自己设规则，对某个动作选允许、禁止或者需要批准。会影响账户或者对外分享信息的动作，会先经过一个自动审核。改密码这类事，永远由用户自己做。它可以用你保存的密码登录网站，但密码不会给模型看到。
小苇
谁能用？
大雨
现在是 Pro 和 Business Premium 用户，第一个 dot 不另外收费。欧洲经济区、瑞士和英国的 Pro 用户暂时用不了。企业版、教育版可以在管理员打开后试用测试版。OpenAI 还在预告一种给公司用的「专职 dot」，有自己的身份和凭证，负责采购、处理发票、客服这类固定岗位，先做企业试点。

📎 OpenAI launches dots, always-on AI agents with their own cloud computers · TNW

小苇
我注意到 OpenAI 自己写了一句「dots 仍可能出错，重要的工作一定要检查」。
大雨
对。而且同一周 OpenAI 刚公布过，它的 agent 把五十三张用户图片传到了公开图床上。所以 dots 的审批规则写得这么细，可以理解。
小苇
我想问的是另一点。dot 在后台只读，听起来安全。但它读的是你所有连接的应用：邮件、Slack、日历。只读本身就意味着它知道的东西比你任何一个同事都多。
大雨
这是对的。权限管的是它能做什么，管不了它知道什么。

◈ 二 · GPT-6.1 Sol：接近 Astra，价格五分之一

大雨
同一天发布的还有 GPT-6.1 Sol。它是 Sol 的升级版，OpenAI 的说法是「接近 Astra 的智能，五分之一的价格」。
小苇
具体多少钱？
大雨
API 里每百万输入 token 两美元，输出十美元。Astra 是十美元和五十美元。缓存输入每百万 token 一毛钱。
小苇
能力上呢？
大雨
按 OpenAI 自己的测试：在 DeepSWE v1.1 这个真实代码库里的软件工程测试上，Sol 和 Astra 分数一样；在多步骤业务流程的测试上，比 Anthropic 的 Opus 5.5 高两分多，成本大约三分之一；在电脑操作测试 OSWorld 2.0 上，比 Astra 低两分左右。最难的科研任务，OpenAI 说还是用 Astra。
小苇
这些都是 OpenAI 自己测的。
大雨
对，竞争对手的分数取自公开报告，没有第三方复测。另外有一个安全测试的数字值得说：遇到「拒绝访问」这类明确限制时，Sol 有百分之二十三点五的情况会想办法绕过去。上一版 Sol 是百分之六十四，Astra 是百分之十七。
小苇
降了很多，但四次里还有一次。
大雨
OpenAI 说这些测试大多是低风险场景，也没开产品里的全部防护。还有一个背景：OpenAI 已经取消了原定十月发布的 GPT-6.1 Astra，原因是没通过安全测试。

📎 OpenAI releases GPT-6.1 Sol at a fifth of GPT-6 Astra's token prices · TNW

小苇
需求怎么样？
大雨
OpenAI 负责 Codex 的 Thibault Sottiaux 昨天发推说，6.1 Sol 几乎是他们需求最大的模型，API 和订阅都是。发布后 ChatGPT 和 Codex 负载很高，他们加了算力，说速度会提升到前一天的将近两倍。
小苇
最强的模型是 Astra，但用的人最多的是便宜一档的 Sol。对多数工作来说，够用加便宜比最强更重要。

◈ 三 · Gemini 4 Argon：先给网络安全防守方

大雨
九月三十号周三，Google 发布 Gemini 4 Argon，说是它最强的模型。
小苇
怎么个强法？
大雨
Google 说它擅长三件事：真实的软件工程、法律和金融这类企业知识工作，还有网络安全防守。它说 Argon 能「自主发现、验证和修补关键软件漏洞」。输出上限扩到了一百万 token。Google 自己的对比是在十八项基准里领先十二项，对手是 GPT-6 Astra 和 Claude Opus 5.5。
小苇
谁能用？
大雨
这是这条新闻最特别的地方：现在只给 Google 的一批网络安全合作方用，通过一个叫 Fairwind 的安全计划。普通开发者暂时拿不到。Google 公布的 API 价格是首发期每百万输入 token 两美元、输出十美元，之后涨到四美元和二十美元。

📎 Google releases Gemini 4 Argon, called its most powerful model yet · TechCrunch

小苇
先给防守方，是什么考虑？
大雨
一个能自己找漏洞、写修补的模型，也能自己找漏洞、不写修补。先让防守方用一段时间，把漏洞补上，再放开。Anthropic 同一天发了一篇报告，说智谱的开源模型 GLM-5.3 已经是美国 NIST 测过的网络攻击能力最强的开源模型，大约落后美国最前沿系统四个月。

📎 GLM-5.3 and the spread of advanced cyber capabilities · Anthropic

小苇
所以四个月之后，任何人都可以下载一个差不多能力的模型。
大雨
Anthropic 的意思大致是这样。智谱那边也回应说，GLM-5.3 的免费漏洞服务已经私下报告了四千多个可能的漏洞，涉及三百八十九个开源项目。同一个能力，两边各说一半。

◈ 四 · 同一天：FTC 开始调查，白宫签自愿协议

大雨
也是九月三十号，FTC 对 OpenAI、Anthropic 和做模型评估的 METR 开始了一项大范围调查。据《华盛顿邮报》和《华尔街日报》，FTC 要看的是：agent 出的事故，以及这些公司对外说的安全承诺，有没有违反现有的消费者保护法。
小苇
是因为七月 Hugging Face 那件事吗？
大雨
报道说调查在那件事公开之前就开始了。所以它不只是针对一次事故，而是在试：现有法律能不能管到前沿 agent 出的问题。

📎 FTC launches broad investigation into Anthropic, OpenAI · The Washington Post

小苇
白宫那边呢？
大雨
同一天，特朗普和 OpenAI、Anthropic、英伟达、Google、Meta、SpaceX、微软、AMD、Palo Alto Networks 的负责人签了一份自愿安全协议，内容是内部评估、外部审计、董事会审查，还有定期的标准会议。特朗普说它「在道德上有约束力」，协议本身说以后可能写进法律。

📎 Trump, tech executives sign voluntary AI controls · CBS News

小苇
还有一个改名的行政令？
大雨
对。九月二十九号的行政令要求行政部门在法律允许的地方，把「人工智能」改称「超级智能」，简称 SI。已有的法规和合同不变，科学顾问有六十天提出一个法律定义。这个行政令本身没有新的安全要求。

📎 Inaugurating the Era of Super Intelligence · The White House

小苇
一个机构用现有法律去查，另一个机构让公司自己承诺。哪个会先起作用？
大雨
现在说不准。但对用 agent 的人来说，FTC 这条更实际：如果它认定 agent 出的事属于消费者保护的范围，以后公司对 agent 的安全说法就要能拿出证据。

◈ 今天这四条串起来

四条放在一起看，我的感觉是：模型越来越便宜，agent 越来越常开，管它的规则还在写。

他怎么说？
